# Local Data Security

## Scope

Local protection covers databases, configuration, caches, indexes, models, attachments, exports, backups, queues, temporary files, crash data, and operating-system integration.

## Controls

Store files under least-privilege per-user locations with restrictive permissions. Separate canonical data, secrets, disposable caches, and exports. Validate paths and permissions at every privileged operation. Prevent untrusted renderers, imported content, models, and plugins from direct storage access.

Local records use transactions, integrity constraints, revisions, audit evidence, crash recovery, and corruption detection. Sensitive caches inherit source classification and retention. Temporary plaintext is minimized, safely scoped, and cleaned, while acknowledging deletion limits on modern storage.

Device compromise can defeat some application controls; the product accurately recommends OS account security, screen lock, full-disk encryption, updates, and protected backups without claiming enforcement it cannot verify.

## Failure behavior

Missing keys, unsafe permissions, corruption, or incompatible schema block unsafe writes and offer verified recovery. The application never silently creates an empty replacement.

## Acceptance criteria

- Cross-user access, path escape, disk-full, crash, and corruption tests pass.
- Private content cannot leak through caches, temp files, thumbnails, or previews.
- Export and backup protections are disclosed separately from live-store protection.
