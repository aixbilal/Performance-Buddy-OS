# Source-Grounded Testing

## Purpose

Ensure practice questions, answers, and explanations are traceable to permitted course materials, notes, or other approved references.

## Grounding contract

Each item stores source IDs, precise locations, source versions/checksums, retrieved passages, generated-at time, model/provider when used, and grounding-validation status. The answer key distinguishes source fact from derived reasoning.

## Rules

Permissions are checked at retrieval and generation. A source conflict or insufficient coverage is surfaced. AI cannot convert its own prior response into an authoritative source. External knowledge may be allowed only when the test explicitly declares that scope. Changed sources mark dependent items stale for review.

## Privacy

Remote generation receives only required passages under explicit provider permission. Restricted notes remain local or excluded. Provider exposure is auditable.

## Acceptance criteria

Users can open supporting sources after the attempt, citations support the intended answer, unavailable grounding blocks authoritative presentation, and lexical/manual test workflows remain available offline.
