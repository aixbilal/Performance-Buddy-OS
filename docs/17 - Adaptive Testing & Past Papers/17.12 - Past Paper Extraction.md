# Past Paper Extraction

## Purpose

Extract candidate sections, questions, marks, instructions, topics, and answer references from permitted past-paper files while preserving page-level provenance.

## Pipeline

Validate file and permission; preserve checksum; extract embedded text or run approved OCR; segment pages/sections/questions; capture numbering and marks; propose course/topic links and question types; run consistency checks; preview low-confidence fields; publish only after review.

## Rules

OCR and AI output are `IMPORTED DRAFT`, not source truth. Original page image/text location remains linked. Unreadable symbols, diagrams, tables, code, or equations stay unresolved. The extractor never invents missing question text or marks. Reprocessing uses extractor/version identity and preserves prior reviewed output.

## Privacy and capability

Local deterministic extraction is preferred where feasible. Remote OCR/AI is optional and explicitly consented. Failure leaves the source unchanged and other pages usable.

## Acceptance criteria

Every extracted field points to a page region, uncertainty is reviewable, retries are idempotent, and published questions reproduce the source meaning.
