# Test Generation

## Purpose

Create coherent practice tests from approved question banks or permissioned knowledge sources while controlling scope, difficulty, format, duplication, and answer leakage.

## Input contract

Course/path, topics, source set, learning objectives, question types, difficulty distribution, item count or duration, assistance mode, language, exclusions, and random seed where deterministic selection is used.

## Pipeline

Validate permissions and coverage; retrieve sources; select or generate candidates; attach citations and answer rationale; run schema, duplication, ambiguity, solvability, and source-entailment checks; preview limitations; freeze an immutable test version.

## Rules

`CORE` assembles reviewed bank items. AI generation is `V1`. Generated items remain drafts until automated validation and, where consequence warrants, human review. Answer keys are stored separately from the attempt surface. Unsupported source coverage produces fewer questions or a gap report, not fabricated facts.

## Acceptance criteria

Tests match requested scope, preserve source provenance, do not expose answers early, identify AI-generated items, and remain usable when AI is unavailable.
