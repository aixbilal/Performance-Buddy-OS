# Scoring

## Purpose

Score practice attempts reproducibly while distinguishing objective checks, rubric judgments, AI suggestions, and unresolved responses.

## Scoring modes

Exact match, normalized match, set comparison, numeric tolerance, deterministic code tests, rule-based partial credit, human rubric review, and AI-proposed rubric scoring are distinct modes.

## Rules

Every item declares maximum points, scoring version, partial-credit policy, penalties if any, units/tolerance, and review authority. Decimal arithmetic and rounding are explicit. AI-proposed scores require human confirmation and cannot be disguised as objective. Invalid questions may be excluded with an auditable reason rather than counted wrong.

## Output

Store raw points, maximum, per-item breakdown, excluded items, unrounded/rounded totals, scorer, rule version, uncertainty, and review state. Practice results remain separate from Phase 13 marks.

## Acceptance criteria

Approved fixtures reproduce scores exactly, rescoring preserves prior runs, open-response uncertainty is visible, and a questionable answer key can be challenged without losing the attempt.
