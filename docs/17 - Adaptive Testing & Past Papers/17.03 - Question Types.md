# Question Types

## Purpose

Define supported practice-item contracts so capture, scoring, evidence strength, and accessibility remain consistent.

## Baseline types

Single-choice, multiple-select, true/false with justification, short answer, numeric response, worked problem, code response, ordering, matching, explanation, and essay/project prompt may be represented. Each type declares prompt, response schema, answer/rubric, scoring mode, source links, difficulty, and accessibility text.

## Rules

- Multiple-choice distractors must be plausible without introducing unsupported claims.
- True/false alone provides limited evidence unless reasoning is captured where appropriate.
- Numeric items declare units, tolerance, precision, and accepted forms.
- Code and open responses require deterministic tests or a reviewed rubric.
- Generated rubrics are proposals and cannot claim objective correctness beyond their sources.
- Question type does not by itself determine difficulty.

## Acceptance criteria

Each type validates input, supports keyboard/screen-reader use, preserves the raw response, identifies scoring authority, and degrades to manual review when automated scoring is unsafe.
