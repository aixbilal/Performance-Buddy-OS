# V3 Build Phase

## Outcome

`V3` is the future Personal Performance Intelligence layer for highest-value next action, cross-domain reallocation, long-horizon reasoning, and specialist/manager synthesis.

## Entry criteria

Mature trusted histories across authorized domains; stable CORE/V1/V2 contracts; protected constraints; validated cross-domain context/provenance; specialist and manager schemas; standard/deep reasoning policies; cost/resource controls; and consequence-specific V3 evaluations.

## Build sequence

First prove a deterministic/V2 baseline for cross-domain choice. Add standard reasoning with limited specialists, then deep reasoning only for eligible high-value cases. Each specialist cites evidence and constraints; manager synthesis cannot invent consensus or override hard validation.

Long-horizon recommendations preserve academic, development, fitness/recovery, language, routine, money separation, and human control. There is no universal life score. Uncertainty, alternatives, reversibility, and what would change the recommendation are explicit.

## Exit gates

V3 must outperform simpler baselines on value and explanation while meeting stricter safety, stability, cost, latency, privacy, and hallucination thresholds.

## Acceptance criteria

- Highest-value action remains a recommendation, not autonomous authority.
- Specialist disagreement and missing context are visible.
- V3 can be disabled without stranding lower-level data/workflows.
