# V2 Build Phase

## Outcome

`V2` adds an Adaptive Coach that analyzes history, detects patterns/friction, compares study/workload outcomes, produces predictive risk signals, proposes adaptive schedules, and learns from recommendation outcomes.

## Entry criteria

Reliable longitudinal CORE evidence; stable V1 recommendation/approval contracts; analytics definitions; sufficient data-quality/coverage; causal-language boundaries; scheduled run controls; recommendation memory and outcome schema; and V2 evaluation datasets.

## Build sequence

Begin with descriptive historical windows and transparent pattern rules. Add cross-domain correlation with permission intersection, friction/study-effectiveness analysis, carefully calibrated risk signals, proposals, and outcome review. Correlation never becomes causal fact automatically.

Scheduled analysis is inspectable, cancellable, resource/cost-bounded, and cannot commit proposals. Sparse/stale/biased data yields uncertainty or abstention. Rejected recommendations are respected.

## Exit gates

V2 demonstrates actionable value above V1/deterministic baselines without privacy, manipulation, stability, safety, or false-causality regression.

## Acceptance criteria

- Every finding states window, evidence, method, uncertainty, and limitations.
- Cross-domain processing uses intersection of permissions.
- Outcome analysis does not optimize acceptance at the expense of user goals/control.
