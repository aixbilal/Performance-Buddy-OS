# 33.03 — Local Database Requirements

## Requirements

The local database must provide ACID transactions, constraints, foreign keys or equivalent integrity, indexes, deterministic queries, migration support, crash recovery, concurrent-reader/safe-writer behavior, backup/export consistency, corruption detection, and supported encryption/key integration. Exact engine/ORM are `RESEARCH REQUIRED` in Phase 44.

## Operational rules

Use owner repositories and prepared/typed access, not UI/model queries. Enable integrity settings at every connection. One business command commits atomically with revision and audit/event records. Long migrations/index work expose progress and recovery. Sensitive logging is minimized.

The database must open without network. Failure to open, migrate, or verify integrity blocks unsafe writes and offers verified backup/restore/recovery paths; it never creates a blank replacement silently.

## Acceptance criteria

- Power-loss, disk-full, lock/contention, migration interruption, and corruption tests pass.
- Backups restore to matching counts/hashes/invariants.
- CORE performance targets hold on minimum supported local hardware.
