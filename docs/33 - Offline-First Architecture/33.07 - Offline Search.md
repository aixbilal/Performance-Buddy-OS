# 33.07 — Offline Search

## Baseline

Global and knowledge search use a local permission-partitioned lexical/metadata index. It covers canonical entities and authorized vault/file references with source IDs, checksums, headings/fields, offsets, parser/index versions, and freshness.

## Rules

The index is disposable, rebuildable, and never authoritative. Ingestion and query enforce permissions. File/source changes incrementally update; permission revocation purges projections. Corrupt or incompatible generations are quarantined and rebuilt while direct domain navigation remains available.

On-device embeddings/reranking are optional `LOCAL` after evaluation; disabling them leaves lexical search. Network, remote embeddings, or provider responses are never required for CORE search.

## Acceptance criteria

- Airplane-mode queries return source-linked match reasons.
- Index loss/corruption/partial coverage is visible and recoverable.
- Restricted content cannot influence ranking, snippets, metadata, or query logs.
