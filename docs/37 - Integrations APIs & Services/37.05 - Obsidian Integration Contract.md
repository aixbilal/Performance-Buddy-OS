# Obsidian Integration Contract

## Contract

This interface implements Phase 16 without making Performance Buddy OS the vault owner. It selects an approved vault, scans permitted Markdown and attachments, parses allowlisted metadata, creates stable references, maintains local projections, monitors change, and exposes source-grounded retrieval.

## Authority

The vault file is authoritative for its text. Parsed metadata, lexical indexes, embeddings, classifications, and summaries are disposable or derived projections. Every result resolves to a permitted file and location with provenance; AI output cannot overwrite the source.

## Access rules

CORE access is local and read-only by default. Path and privacy rules follow 37.04 and Phase 16. Semantic indexing is optional `LOCAL`; remote embeddings are optional `CLOUD` and require file/category/provider consent. Revocation promptly stops access and invalidates prohibited indexes.

Future writes require a separately approved capability, exact diff preview, encoding preservation, compare-before-write, atomic replacement, backup, conflicts, and undo. No Obsidian plugin is required.

## Acceptance criteria

- Disabling integration leaves the vault unchanged.
- Rename, deletion, duplicate, and concurrent-edit tests preserve reference integrity.
- Search citations never expose inaccessible paths or snippets.
