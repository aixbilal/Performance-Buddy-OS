# 25.06 — Local Inference Runtime Options

## Status

The exact runtime is `RESEARCH REQUIRED`. This document defines the selection and adapter contract so implementation does not prematurely lock to a vendor or model format.

## Runtime criteria

Evaluate operating-system and hardware coverage, model/quantization support, structured decoding, embeddings, cancellation, streaming, batching, memory controls, acceleration backends, sandboxing, signed updates, license, maintenance health, observability, and predictable error semantics.

## Adapter contract

The local adapter reports runtime/model versions, capabilities, context limit, current readiness, resource estimate, and supported output modes. It accepts a Phase 24 run request and returns normalized output, usage estimates, timing, finish reason, and typed failure. Provider-specific objects do not cross the adapter boundary.

## Lifecycle

Installations verify source, license, size, signature or hash, and compatibility before activation. Updates are staged, benchmarked, and reversible. Model caches have explicit locations, quotas, integrity checks, and removal behavior. The runtime does not automatically expose a network listener; if an implementation requires one, it binds locally, authenticates, and is threat-reviewed.

## Acceptance criteria

- At least one deterministic test double validates the adapter independently of a model.
- Runtime replacement does not alter domain authority, schemas, or approval rules.
- Failed install/update leaves the prior approved runtime or CORE fallback usable.
