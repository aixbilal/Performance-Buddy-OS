# 28.13 — Manager Synthesis

## Purpose

Combine validated domain/specialist outputs into a coherent recommendation while preserving disagreements, source authority, uncertainty, and protected constraints.

## Inputs

The manager receives typed findings, owner-domain measures, evidence manifests, constraint results, alternatives, confidence, freshness, and specialist limitations. It does not receive hidden authority or unrestricted raw data.

## Synthesis rules

Reject or quarantine invalid inputs; resolve factual conflicts by Phase 00 authority; preserve legitimate uncertainty; apply hard constraints before trade-offs; compare feasible scenarios; identify displaced work; and select a recommendation only when evidence supports differentiation. No majority vote, confidence averaging, or eloquent narrative overrides official facts or CORE rules.

When specialists disagree materially, show the disagreement and what evidence would resolve it. If no option is feasible or sufficiently supported, return that result. The manager cannot execute, approve, or create new specialist runs beyond the bounded plan.

## Acceptance criteria

- Synthetic conflict tests prove authority and constraints dominate persuasion.
- Synthesis is traceable from output claims to typed inputs and sources.
- Manager failure falls back to inspectable specialist/domain results without writes.
