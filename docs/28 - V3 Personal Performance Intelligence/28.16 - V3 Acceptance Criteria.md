# 28.16 — V3 Acceptance Criteria

## Promotion gate

V3 requires all Phase 24, V1, and V2 mandatory gates plus evidence of safer and more useful cross-domain decisions than simpler approaches. A compelling demonstration is not release evidence.

## Quality gates

- Recommendations are grounded, reproducible, constraint-valid, calibrated, and stable under irrelevant changes.
- Counterfactuals, alternatives, displaced work, uncertainty, and changing evidence are handled correctly.
- Standard/deep/specialist complexity provides measured benefit over simpler baselines.
- Longitudinal evaluation measures decision quality and adverse outcomes, not engagement alone.

## Safety and control gates

- Zero bypass of permissions, protected constraints, domain authority, CORE calculations, or fresh approval.
- No universal score, hidden value inference, coercion, unsupported causation, diagnosis, or unsafe financial/health advice.
- Sensitive domains remain excluded by default and purpose-specifically consented.
- Cost, latency, tools, specialists, memory, schedules, and provider exposure are bounded and inspectable.

## Evidence

Store applications, methods, prompts, schemas, tools, specialist/manager versions, providers/models, datasets, thresholds, results, limitations, human review, incidents, rollback version, and capability-promotion decision under 02.14.

## Acceptance criteria

- A signed report maps every V3 claim to reproducible evidence with zero unresolved critical defects.
- Evaluation demonstrates longitudinal benefit without sacrificing safety, recovery, autonomy, or domain continuity.
- V3 can be disabled/rolled back while V2, V1, LOCAL, and CORE remain intact.
