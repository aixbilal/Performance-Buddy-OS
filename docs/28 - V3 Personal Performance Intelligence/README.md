# Phase 28 — V3 Personal Performance Intelligence

## Purpose

Phase 28 defines the planned highest intelligence layer of Performance Buddy OS: permissioned, long-horizon reasoning across domains that recommends the highest-value feasible next action or allocation and explains the trade-offs.

## Status and authority

V3 is a long-term design target, not an initial-release claim. It requires mature CORE, V1, and V2 evidence plus promotion under Phase 02. Higher intelligence never gains policy or write authority. Domain records, Phase 23 rules, and fresh human approval remain authoritative.

## Core contract

V3 receives an approved objective, horizon, domains, evidence, preferences, and constraints. It separates facts, derived measures, assumptions, and hypotheses; generates feasible alternatives; validates them deterministically; and returns one recommendation with alternatives, uncertainty, trade-offs, and review triggers.

## Invariants

Protected sleep, safety, recovery, fixed commitments, permissions, official facts, and domain boundaries are hard constraints. There is no universal life score. Money, prayer, reflection, smoking, and private routine data do not become hidden optimization inputs. Recommendations remain proposals.

## Architecture principle

Use the simplest evaluated reasoning pipeline. Specialist or manager architecture is justified only by evidence that a single bounded call or native sequential workflow is insufficient.

## Acceptance criteria

- All 16 numbered files exist with exact names and `V3` labels.
- Every recommendation is evidence-linked, feasible, reversible where possible, and approval-gated.
- V3 can be disabled without affecting V2, V1, LOCAL, or CORE.
