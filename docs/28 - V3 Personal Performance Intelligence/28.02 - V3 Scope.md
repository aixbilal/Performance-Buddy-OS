# 28.02 — V3 Scope

## Included scope

V3 supports user-requested standard reasoning and explicitly approved deep reasoning over multi-week or semester horizons. It may recommend a highest-value next action, compare cross-domain plans, propose academic/development/recovery reallocations, model scenario trade-offs, and synthesize specialist analyses.

## Preconditions

Mature domain contracts; stable deterministic rules; permission-safe provenance; reliable V1 approval; calibrated V2 patterns/outcomes; explicit goals/preferences; sufficient coverage; cross-domain safety evaluations; bounded cost/latency; and rollback/deactivation paths.

## Output classes

`NEXT_ACTION_RECOMMENDATION`, `ALLOCATION_PROPOSAL`, `SCENARIO_COMPARISON`, `REVIEW_REQUEST`, `INSUFFICIENT_EVIDENCE`, `NO_FEASIBLE_OPTION`, or `BOUNDARY_REFUSAL`. Each output declares horizon, freshness, confidence, and expiration.

## Trigger

V3 runs only from a user request or separately approved analysis workflow. It does not continuously optimize or initiate unbounded planning. Scheduled precursor analyses may prepare evidence but cannot commit actions.

## Acceptance criteria

- Each use case declares objective, domains, horizon, evidence threshold, constraints, output, and fallback.
- V3 adds evaluated value beyond V2 proposals and deterministic planning.
- Unsupported scope degrades to V2/V1/CORE instead of simulating capability.
