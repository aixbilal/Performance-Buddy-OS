# 28.01 — V3 Vision

## Vision

V3 helps the user answer: “Given my real commitments, current trajectory, recovery, goals, and available time, what matters most next—and why?” It supports thoughtful allocation across academics, development, fitness/recovery, routines, and secondary skills without pretending to possess a complete model of the person.

## Desired experience

The recommendation is calm, specific, and bounded: an action or allocation, relevant evidence, protected constraints, what is deferred, alternatives, uncertainty, and a review point. The user can inspect reasoning inputs, correct them, choose another option, or do nothing without pressure.

## Success definition

Success is not maximum activity, streaks, hours, grades, or one composite score. It is improved decision quality over time: fewer infeasible plans, better protection of sustainable capacity, timely attention to high-consequence work, continuity across core systems, and user trust/control.

## Long-term posture

V3 is a decision-support capability, not an autonomous manager. Personal values remain user configuration; behavior does not silently become preference. Outcomes inform future proposals only through governed V2/V3 memory and evaluation.

## Acceptance criteria

- User research confirms recommendations are understandable, useful, and non-coercive.
- The vision remains compatible with offline CORE and personal-first strategy.
- No success metric rewards violating protected constraints or maximizing one domain.
