# Knowledge Domain

## Purpose

Define topics, sources, notes, learning evidence, confidence, retrieval, and the boundary with external Obsidian storage.

## Responsibilities

Knowledge owns topics/subtopics, source references, note/attachment links, lecture material relationships, learning evidence, confidence estimates, source-grounded retrieval, and knowledge search semantics.

Obsidian remains the external knowledge-storage layer. Performance Buddy OS stores governed references, metadata, indexes, and evidence needed for control/intelligence; it does not silently replace or rewrite the vault.

## Core concepts

Topic identity, source provenance, note reference, evidence item, evidence type/weight, confidence assessment, retrieval result, and course/development linkage. Confidence is evidence-based and explainable; time spent alone is insufficient.

## Interactions

Academic and Development attach topics and learning requirements. Adaptive Testing produces attempts and mistakes as evidence. Analytics observes trends. Intelligence retrieves permissioned sources for explanation, testing, and proposals.

## Invariants

Source text and AI interpretation remain distinguishable. Missing evidence means unknown, not weak. Indexes are rebuildable projections. External file deletion/movement produces a recoverable broken-reference state rather than silent data substitution.

## Privacy

Vault selection and folder/file permission boundaries are explicit. Retrieval sends only necessary content to any model and records provider exposure where applicable.

## Acceptance criteria

Knowledge remains searchable offline where indexed, evidence provenance is traceable, confidence is explainable, and vault authority is preserved.
