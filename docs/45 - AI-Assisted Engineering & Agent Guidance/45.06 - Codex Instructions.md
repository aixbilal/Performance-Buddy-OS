# Codex Instructions

## Operating contract

Codex must read the locked blueprint, `00.19 - AI Coding Agent Reading Order.md`, applicable repository instruction files, requested owner documents, and relevant architecture, security, data, testing, and roadmap material before substantive edits. More specific repository instructions apply within their scope but cannot override the locked baseline or explicit human direction.

## Execution rules

- Inspect the workspace, current changes, available scripts, and existing patterns before editing.
- Define a bounded outcome, reuse expectations, acceptance criteria, tests, and conditions requiring escalation.
- Preserve unrelated and user-authored changes; never claim a clean state without checking.
- Prefer small reviewable patches and existing project tools. Do not add dependencies or restructure architecture without approval.
- Use safe read-only investigation freely within scope. Request approval before material external effects, destructive actions, restricted writes, or new authority.
- Run risk-proportionate validation, inspect results, fix in-scope defects, and rerun affected checks.
- Never expose secrets in commands, logs, prompts, patches, fixtures, or reports.

OpenAI's current model guidance recommends explicit instructions about reuse, delegation, test expectations, acceptance criteria, and when an agent should continue or ask for help. Project rules remain authoritative even as Codex interfaces and models change: <https://developers.openai.com/api/docs/guides/latest-model?model=gpt-5.5>.

## Handoff

Lead with the result. List files changed, checks performed, defects fixed, limitations, and exact blockers. Do not say a file was written or a check passed unless tool evidence confirms it.

## Acceptance criteria

- Codex work stays inside authorized scope and preserves repository state.
- Tests and acceptance criteria are explicit and evidenced.
- Escalation occurs for material decisions, not ordinary safe implementation details.
- The handoff is accurate, reproducible, and free of concealed failures.
