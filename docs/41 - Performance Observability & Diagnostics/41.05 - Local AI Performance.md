# Local AI Performance

## Scope

Measure model load/unload, time to first output, total latency, tokens/units per second, structured-valid completion, memory and GPU memory, CPU/GPU utilization, storage, thermal behavior, battery impact, cancellation, and resource release.

## Qualification

Benchmarks record device/OS/architecture, CPU features, GPU/backend/driver, total/available memory, runtime/model/quantization, context, batch, threads, cache, prompt/schema/tool versions, and cold/warm state. Eligibility is distinct from real-time availability.

CORE responsiveness is reserved. Local AI pauses, reduces context/batch/concurrency, unloads, or cancels under interactive load, low memory/storage, battery saver, focus activity, or thermal pressure. A faster model does not pass if structured quality, safety, privacy, or grounding gates fail.

Raw hardware inventory remains local unless diagnostic sharing is explicitly enabled. Unsupported devices receive a clear fallback rather than endless loading.

`RESEARCH REQUIRED`: approve hardware tiers and application-specific latency/resource budgets through Phase 25/40 benchmarks.

## Acceptance criteria

- Stress tests preserve CORE response and data integrity.
- Cancellation and failure release resources within an approved bound.
- Model/runtime changes rerun performance and quality regression suites.
