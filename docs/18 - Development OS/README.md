# Phase 18 — Development OS

## Purpose

Development OS turns full-stack software engineering and AI-application engineering ambitions into chained learning paths, deliberate practice, projects, milestones, notes, and evidence of independent capability.

| Range | Responsibility |

## Ownership boundaries

Phase 11 owns generic learning paths and milestones. Phase 09 owns session execution. Knowledge OS owns topics, sources, and confidence. Phase 18 owns development-specific learning, project, evidence, and practice semantics. Phase 44 owns technology research and architecture decisions for Performance Buddy OS itself.

## Invariants

1. Tutorial completion, code volume, elapsed time, commits, or AI output alone do not prove skill.
2. Useful evidence includes independent implementation, tests, debugging, explanation, refactoring, and transfer.
3. AI-assisted work is permitted but provenance and verification remain visible.
4. AI-off practice is deliberate, configurable, and followed by review where useful.
5. Development is a core long-term domain, not automatically secondary to academics.
6. Academic risk and protected sleep/recovery may temporarily change allocation.
7. Framework and tool choices remain `RESEARCH REQUIRED` until approved through Phase 44.
