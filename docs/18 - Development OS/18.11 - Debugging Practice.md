# Debugging Practice

## Purpose

Develop systematic fault isolation and correction rather than relying on random changes or immediate AI solutions.

## Practice cycle

Reproduce reliably; state expected versus actual behavior; minimize the case; gather logs/observations safely; form ranked hypotheses; test one variable at a time; identify root cause; implement the smallest correct fix; run regression tests; and record the lesson.

## Evidence

Reproduction steps, failing test, diagnostic observations, hypotheses, experiments, root-cause explanation, patch, passing regression test, and prevention note. A copied fix without understanding is weak evidence.

## Rules

Never expose secrets or personal data in logs. Destructive experiments require isolation and backup. AI may suggest hypotheses after the configured independent attempt; suggestions are tested rather than trusted. Environment and dependency versions remain part of provenance.

## Acceptance criteria

Practice records distinguish symptom and cause, fixes include regression evidence, unsafe logging is avoided, and later reviews can reproduce the reasoning path.
