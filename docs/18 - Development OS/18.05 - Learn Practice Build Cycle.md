# Learn Practice Build Cycle

## Purpose

Turn technical information into usable engineering skill through repeated explanation, independent application, feedback, correction, and transfer.

## Cycle

1. Learn from permitted authoritative sources.
2. Explain or retrieve the concept without copying.
3. Practice in a bounded exercise.
4. Build it into a meaningful feature or small project.
5. Test, inspect, and review behavior.
6. Debug and correct failures.
7. Explain trade-offs and refactor where useful.
8. Reapply later in a different context.

## Rules

The cycle can iterate and does not require equal time in every stage. Building before full theory is allowed when feedback is captured. A passing tutorial demo is not sufficient if the user cannot modify or explain it. AI may assist at declared stages; independent checkpoints preserve capability evidence.

## Acceptance criteria

Modules include retrieval, practice, build, and verification evidence; errors feed later work; and advancement reflects application and explanation rather than passive completion.
