# Course-to-Note Linking

## Purpose

Connect versioned Academic OS courses to vault notes while preventing ambiguous codes or folder names from becoming official relationships.

## Link sources

Links may originate from explicit stable IDs in frontmatter, a user-confirmed mapping, course-folder configuration, note links, or importer suggestions. Explicit stable IDs have highest confidence; heuristics create candidates only.

## Resolution

Match against curriculum context, course code, title, term/offering where relevant, and configured aliases. Ambiguous matches remain `UNRESOLVED`. One note may link to multiple courses with an explicit reason; one course may reference many notes.

## Rules

Renamed files retain links through stable reference matching where possible. A course code alone is not globally unique. Linking a note does not prove topic coverage, attendance, or mastery. Broken references remain visible and recoverable.

## Acceptance criteria

Every active link has provenance and confidence/verification state, ambiguity requires review, curriculum version is respected, and unlinking does not delete the note.
