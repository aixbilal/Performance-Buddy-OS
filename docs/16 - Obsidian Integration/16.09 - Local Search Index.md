# Local Search Index

## Purpose

Provide the offline lexical and metadata index required by Knowledge Search and Global Search.

## Index contract

Entries include vault/file IDs, content checksum, parser version, permitted fields, token/term data, headings, tags, links, timestamps, privacy partition, and source offsets. The index has a generation ID, schema version, build status, and coverage summary.

## Rules

The index is disposable and rebuildable from permitted sources. It never outranks files. Permission partitions apply during ingestion and query, preventing restricted snippets from entering an unauthorized result. Query logs are local, minimized, and optional.

## Operations

Support initial build, incremental update, integrity check, compaction, permission purge, and full rebuild. A corrupt index is quarantined and rebuilt; it never causes vault modification.

## Technology status

Exact search library and storage engine are `RESEARCH REQUIRED`. `CORE` behavior cannot depend on network or embeddings.

## Acceptance criteria

Airplane-mode search works, permission revocation purges affected projections, index loss is recoverable, and each result identifies match reason and source location.
