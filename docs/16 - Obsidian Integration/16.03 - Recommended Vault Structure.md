# Recommended Vault Structure

## Purpose

Offer an optional structure that improves course and topic linking while remaining compatible with existing personal vault organization.

## Recommendation

Users may organize content by areas such as university, courses, development, language, references, and attachments, with course folders containing notes, lectures, assignments, and reviews. This is guidance, not a required migration or locked path convention.

## Rules

- Existing vault structures remain valid.
- Integration relies on configured mappings and metadata, not one mandatory folder tree.
- Folder names do not establish academic truth or privacy classification by themselves.
- Reorganization is never performed during indexing.
- Any future migration must preview moves, update links safely, detect conflicts, create a backup, and require explicit approval.

## Portability

Prefer plain Markdown, relative links where appropriate, standard attachments, and documented frontmatter keys. Obsidian-specific syntax may be indexed but should not be required for core data portability.

## Acceptance criteria

Users can link courses and topics in arbitrary structures, recommended conventions remain optional, and no feature fails solely because the vault differs from the recommendation.
