# Phase 14 — Academic Planning & Study Intelligence

## Purpose

Phase 14 converts verified academic structure, deadlines, assessment state, prerequisite exposure, topic coverage, and learning evidence into explainable study demand. It owns academic risk and allocation concepts, not university policy, grade mathematics, daily calendar mutation, or knowledge truth.

## Document map

| Range | Responsibility |
|---|---|
| 14.01–14.05 | Planning, difficulty, risk, allocation, return |
| 14.06 | Academic study modes |
| 14.07–14.10 | Coverage and evidence sources |
| 14.11 | Requirement recalculation |
| 14.12–14.15 | Exam ramp-up and university mode |

## Ownership boundaries

Phase 12 supplies curriculum, enrollment, and prerequisite facts. Phase 13 supplies marks and labeled scenarios. Phase 15 owns knowledge entities and confidence. Phase 17 owns adaptive tests and past-paper analysis. Phase 08 owns the final daily plan; Phase 09 owns session execution.

## Invariants

1. Hard constraints, fixed commitments, sleep, recovery, and safety filter before study allocation.
2. Exposure and elapsed time are not mastery.
3. Difficulty and risk are explainable estimates with visible missing data.
4. Projections remain scenarios; AI cannot promise grades or invent exam coverage.
5. `CORE` provides deterministic rules and candidate allocations; meaningful plan changes require confirmation.
6. Infeasible demand is reported rather than compressed into an unsafe schedule.
