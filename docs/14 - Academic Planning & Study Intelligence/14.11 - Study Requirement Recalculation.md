# Study Requirement Recalculation

## Purpose

Recalculate remaining academic demand when evidence, deadlines, coverage, assessments, capacity, or mode changes.

## Triggers

New class exposure, completed or partial session, assessment result, changed deadline, topic/prerequisite update, enrollment change, mode transition, corrected evidence, missed plan, or manual request.

## Pipeline

Snapshot the prior requirement; validate new evidence; preserve completed facts; recompute topic/course gaps; update risk and candidate methods; estimate bounded demand; compare with safe capacity; produce minimal changes and explanations; send candidates to Phase 08 for confirmation.

## Rules

Recalculation never rewrites original plans or source evidence. Unknown data cannot default to completion. A university activity may reduce duplicate demand only when its evidence matches the planned outcome. If demand exceeds capacity, show the shortfall and trade-offs.

## Acceptance criteria

Identical inputs reproduce the same requirement, every delta has a reason code, corrections propagate, protected constraints remain intact, and no plan mutation occurs without the proper approval path.
