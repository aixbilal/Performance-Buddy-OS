# Marginal Academic Return

## Purpose

Estimate the likely value of the next bounded study block relative to alternative academic work. It guides allocation without pretending learning or grades are perfectly predictable.

## Factors

Deadline and assessment leverage, prerequisite consequence, current evidence gap, task readiness, opportunity to correct known errors, spacing/retrieval benefit, diminishing returns from recent effort, and feasibility within the available window.

## Rules

- Return is comparative and context-specific, not a universal numeric truth.
- High assessment weight does not automatically dominate if the needed action is unclear or evidence is already strong.
- Repeated passive review may have lower expected return than retrieval or problem solving.
- Uncertain inputs widen the range and surface alternatives.
- Marginal return never justifies violating sleep, safety, or fixed commitments.

## Output

Use a reasoned band or range with evidence, uncertainty, expected outcome, and what would change the estimate. Exact models remain provisional.

## Acceptance criteria

Recommendations prefer actionable evidence-producing work, recognize diminishing returns, avoid false precision, and remain explainable without AI.
