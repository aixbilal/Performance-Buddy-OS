# Course-Level Assessment Overrides

## Purpose

Represent verified differences between a default assessment template and the assessment scheme actually applicable to one course offering or attempt.

## Precedence

An override is valid only when an authoritative source permits or states the difference. The effective scheme is produced field by field from the default plus approved overrides, with provenance retained for both.

## Model

Each override records target course/offering, base template version, changed field, prior value, new value, reason, source, effective date, reviewer, and verification state. Unsupported free-form replacement is prohibited.

## Rules

- Overrides cannot repair a missing default by assumption.
- Weight totals, bounds, pass conditions, and category references are revalidated.
- Historical calculations retain the scheme snapshot used.
- An instructor announcement may be personal-course evidence but its authority and scope must be confirmed.
- Conflicting sources block the affected field.

## Acceptance criteria

The effective scheme is explainable field by field, invalid totals cannot publish, and removing an override restores the verified base without deleting history.
