# Academic Calculation Validation

## Purpose

Define the quality gates required before assessment, grade, SGPA, CGPA, and projection calculations can be trusted.

## Test layers

- unit tests for ratios, weights, decimal precision, rounding, intervals, and zero denominators;
- boundary tests for every grade threshold and maximum/minimum mark;
- policy fixtures for missing, excused, bonus, dropped, repeated, transferred, and exceptional statuses;
- integration tests from imported record through explanation trace;
- property tests for invariants such as no duplicate attempt inclusion;
- reconciliation against independently calculated and official examples when available.

## Release gates

Applicable official policy must be captured and reviewed; fixtures must cite source sections; all material branches must pass; unresolved conflicts must block official classification; migrations require before/after reconciliation; and numeric libraries must use decimal behavior.

## Change control

Policy or formula changes create versions and regression tests for prior rules. Historical calculation snapshots remain reproducible.

## Acceptance criteria

No consequential formula ships from examples alone, failures identify input and rule, and Phase 23 can independently reproduce every approved fixture.
