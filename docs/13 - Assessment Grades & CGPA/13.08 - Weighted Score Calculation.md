# Weighted Score Calculation

## Purpose

Calculate course assessment contributions deterministically from verified marks and an applicable assessment scheme.

## Baseline formula

For a simple weighted item or category, the contribution is `(earned / maximum) × weight`. The course weighted score is the sum of included contributions. This formula applies only when the sourced scheme defines proportional weighting; alternative rules must be explicitly modeled.

## Arithmetic rules

Use decimal arithmetic, retain unrounded intermediate precision, and apply rounding only at policy-defined boundaries. Store original marks, normalized ratios, contributions, exclusions, precision, rounding mode, formula version, and calculation time.

## Exceptional rules

Best-N, dropped items, normalized class marks, bonus caps, make-ups, category averaging, and separate pass conditions require verified rule modules. Unknown required marks yield an incomplete result or scenario range, never an assumed zero.

## Validation

Weights, maximums, duplicate inclusion, category membership, and total contribution are validated before publication.

## Acceptance criteria

The engine reproduces hand calculations for approved fixtures, exposes every term, avoids floating-point drift, and refuses unsupported policy behavior.
