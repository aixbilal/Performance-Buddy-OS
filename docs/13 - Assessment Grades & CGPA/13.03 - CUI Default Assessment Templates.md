# CUI Default Assessment Templates

## Purpose

Define how verified CUI-wide default assessment schemes may be stored and applied. This document intentionally contains no numeric CUI defaults until applicable official sources are approved.

## Current status

Default category names, weights, theory/lab differences, passing conditions, and rounding rules are `RESEARCH REQUIRED` under OQ-003. Common practice, an old score sheet, or an AI answer is not sufficient authority.

## Template contract

A template records university, campus/program/course applicability, course type, effective dates, categories, weights, item rules, pass conditions, source sections, reviewer, verification state, and supersession history.

## Application rules

Templates provide defaults only where their applicability matches the course attempt. A course-level official scheme may override permitted fields under `13.04`. Applying a newer template to a historical attempt requires explicit verified applicability.

## Conflict behavior

Ambiguous or conflicting sources keep the template `UNRESOLVED` and block policy-dependent calculations. Existing verified calculations retain their original template snapshot.

## Acceptance criteria

No CUI numeric default ships without source evidence; applicability is machine-checkable; and every applied field links to a verified source and version.
