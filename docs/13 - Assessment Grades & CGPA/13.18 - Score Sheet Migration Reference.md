# Score Sheet Migration Reference

## Purpose

Define a controlled mapping from a future supplied legacy score sheet into Phase 12/13 entities. No approved score-sheet artifact currently exists in the project, so this document is a migration contract rather than a source-specific mapping.

## Required inventory

Before migration, record file checksum, sheet names, ranges/tables, formulas, named cells, hidden rows/columns, manual overrides, precision, rounding, external links, macros, policy assumptions, sample outputs, and sensitive identifiers.

## Mapping targets

Map curriculum/course identity to Phase 12; attempts and terms to Phase 12; assessment categories/items and marks to Phase 13; grade policy, repeat decisions, SGPA/CGPA outputs, and scenarios to their versioned Phase 13 entities. Display formatting is not treated as semantics.

## Validation process

Preserve the original read-only; import into a candidate workspace; map every populated field; classify hard-coded assumptions; recompute independently; compare cell-level and aggregate results; explain differences; obtain approval; and retain a reconciliation report.

## Safety rules

Spreadsheet formulas are evidence of previous logic, not official CUI policy. Hidden or undocumented constants remain `UNRESOLVED`. Migration is idempotent and transactional; failure leaves approved records unchanged.

## Acceptance criteria

No populated source field is silently dropped, every formula maps or is explicitly retired, discrepancies are resolved or blocked, and sensitive exports are minimized.
