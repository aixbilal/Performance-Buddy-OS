# Target Grade Scenarios

## Purpose

Answer “what marks would be needed?” for a selected course-grade target through transparent, bounded scenarios.

## Workflow

Select course attempt and verified scheme; choose a target grade or score; freeze known marks; identify remaining assessments; enter bounds or assumptions; solve feasible ranges; and display required results with formula lineage.

## Rules

- Targets use the applicable verified grade policy.
- Required values respect assessment maxima, category caps, drop rules, and separate pass conditions.
- Several remaining assessments produce a solution space, not one falsely precise answer.
- An impossible target is reported with the binding constraint and best reachable range.
- Unknown policy produces a policy-gap message rather than a guessed target.

## Presentation

Use neutral language and show alternatives, sensitivity, and remaining weight. A target is a planning aid, not a promise or judgment.

## Acceptance criteria

Solutions substitute back into the calculation correctly, boundary cases are tested, assumptions are editable, and no scenario modifies actual marks.
