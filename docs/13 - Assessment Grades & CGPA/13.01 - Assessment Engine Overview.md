# Assessment Engine Overview

## Purpose

The Assessment Engine converts verified assessment definitions and marks into reproducible course scores, grades, SGPA, and CGPA through versioned deterministic rules.

## Core entities

`AssessmentPolicy`, `CourseAssessmentScheme`, `AssessmentCategory`, `AssessmentItem`, `MarkRecord`, `GradePolicy`, `GradeResult`, `RepeatPolicy`, and `CalculationRun`. Each retains source, applicability, version, and verification state.

## Pipeline

Validate applicability; normalize marks without losing originals; aggregate items by category; apply weights; determine course grade; apply attempt-inclusion policy; calculate SGPA/CGPA; store a result snapshot with inputs and rule versions.

## Publication states

Results are `OFFICIAL-SOURCE MATCHED`, `PERSONAL RECORD`, `DERIVED VERIFIED`, `SCENARIO`, or `UNRESOLVED`. The application must not label a derived value official merely because its arithmetic is correct.

## Capability and failure

All mathematics and validation are `CORE`, offline, deterministic, and tested in Phase 23. AI can explain a result but cannot replace the calculation engine. Missing policy, weight imbalance, invalid bounds, or source conflict blocks publication while preserving a diagnostic trace.

## Acceptance criteria

Identical inputs and rule versions produce identical outputs; every output explains its lineage; and no hidden default controls a consequential result.
