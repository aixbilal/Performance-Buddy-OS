# Knowledge Retrieval

## Purpose

Retrieve a bounded, permissioned set of source passages and metadata for reading, explanation, tutoring, or grounded generation.

## Pipeline

Interpret the query; apply identity and permission filters; retrieve lexical results in `CORE` and optional semantic results under declared capability; deduplicate; rank; return passages with source, location, version, and match reason; then allow a separate consumer to answer with citations.

## Rules

Retrieval results are sources, not generated answers. AI interpretations remain separate and cite supporting passages. Conflicts, stale files, broken references, and missing coverage are visible. Context sent to a model is minimized and provider exposure is logged where applicable.

## Failure behavior

When semantic retrieval is unavailable, fall back to lexical search and filters. If permissions change, cached passages and indexes are invalidated. No result is fabricated to satisfy an empty query.

## Acceptance criteria

Results are source-grounded, reproducible enough to inspect, permission-safe, usable offline at CORE level, and honest when available sources do not answer the question.
