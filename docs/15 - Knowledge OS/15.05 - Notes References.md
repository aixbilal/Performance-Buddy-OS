# Notes References

## Purpose

Link notes from Obsidian, sessions, or other approved locations to knowledge entities without silently moving or rewriting their content.

## Reference model

A note reference stores provider/store, stable path or ID, title, anchors where supported, checksum or modification marker, linked topics, permission scope, index state, and backlink provenance.

## Rules

- The external note remains authoritative for its content.
- Session notes require explicit promotion before becoming durable knowledge references.
- File movement creates a recoverable unresolved reference and may be rematched through safe identity signals.
- Duplicate notes are suggested for review, never merged automatically.
- AI summaries are separate derived artifacts and never overwrite raw notes.

## Privacy

Folder and file permissions constrain indexing, snippets, retrieval, and model exposure. Revoking access removes projections while preserving only permitted reference metadata.

## Acceptance criteria

Backlinks resolve when sources exist, broken links are visible and recoverable, content is never altered without explicit action, and indexes can be rebuilt from governed references.
