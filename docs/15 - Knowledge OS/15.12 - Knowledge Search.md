# Knowledge Search

## Purpose

Provide fast permission-aware discovery across topics, sources, references, and evidence while keeping the index disposable and offline-capable.

## CORE behavior

Local lexical search supports exact text, prefixes, aliases, filters, and metadata facets for entity type, course/path, source, date, evidence, confidence, and status. Results show title, type, context, provenance, match reason, freshness, and canonical route.

## Ranking

Favor exact matches, verified aliases, current context, title/heading matches, and useful recency through documented rules. Richer data must not permanently suppress sparse entities. Users can sort and filter independently of ranking.

## Index rules

Indexes are rebuildable projections with generation version and stale/incomplete status. Source changes trigger incremental updates where possible. Restricted content is excluded or redacted before indexing.

## Enhancements

`LOCAL` may add semantic similarity and synonyms. Disabling it preserves full lexical search. Provider-backed search requires explicit permission and source-scoped exposure.

## Acceptance criteria

Permission tests prevent leakage, results open canonical records, stale indexes are visible, and rebuild or model failure never corrupts sources.
