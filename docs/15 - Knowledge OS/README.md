# Phase 15 — Knowledge OS

## Purpose

Knowledge OS owns topics, source references, note and material links, learning evidence, confidence assessments, permission-aware search, retrieval, and possible graph relationships. It supports Academic and Development without replacing their records or rewriting external knowledge stores.

## Document map

| Range | Responsibility |
|---|---|
| 15.01–15.03 | Knowledge model and topic structure |
| 15.04–15.06 | Sources, notes, and lecture materials |
| 15.07–15.11 | Evidence and explainable confidence |
| 15.12–15.13 | Search and retrieval |
| 15.14 | Graph possibilities and boundaries |

## Ownership boundary

Obsidian remains an external content store; Phase 16 owns its integration. Knowledge OS stores governed references, metadata, indexes, and evidence relationships. Phase 13 owns official marks, Phase 14 owns study demand, Phase 17 owns adaptive test attempts, and source domains retain their facts.

## Invariants

1. Source content, user notes, extracted metadata, and AI interpretation remain distinguishable.
2. Missing evidence means `Unknown`, not weak knowledge.
3. Time, attendance, reading, or file presence alone never proves understanding.
4. Confidence is derived, versioned, explainable, and reversible.
5. Indexes and graph projections are rebuildable; they are not sources of truth.
6. `CORE` lexical search and manual evidence work offline; optional intelligence has a deterministic fallback.
