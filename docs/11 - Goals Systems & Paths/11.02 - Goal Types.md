# Goal Types

## Purpose

Goal types describe how success and review should be interpreted. They support validation and presentation without imposing identical behavior across domains.

## Canonical types

| Type | Meaning | Typical evidence |
|---|---|---|
| Outcome | Reach a defined result | Domain result or artifact |
| Directional | Improve or move toward a direction | Trend plus review evidence |
| Maintenance | Preserve a capability or condition | Consistent qualifying records |
| Project | Deliver a bounded output | Milestones and accepted artifact |
| Learning | Develop demonstrable capability | Practice and assessment evidence |
| Constraint | Stay within a limit or boundary | Owner-validated measurements |

## Rules

A goal has one primary type and may carry tags. Type changes that alter success semantics create a new effective version. A deadline is optional unless intrinsic to the outcome. “Do more” is not sufficient success criteria; directional goals require a review rule and evidence window.

## Domain ownership

The generic type does not redefine grades, fitness safety, financial success, spiritual intention, language proficiency, or project acceptance. The relevant domain supplies those meanings and constraints.

## Acceptance criteria

Each active goal has a valid type, owner, scope, lifecycle state, evidence contract, review cadence, and honest response to missing evidence.
