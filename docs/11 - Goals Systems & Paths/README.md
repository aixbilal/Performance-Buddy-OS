# Phase 11 — Goals Systems & Paths

## Purpose

This phase defines how Performance Buddy OS represents desired outcomes, repeatable systems, executable actions, milestones, reviews, and structured learning paths. It connects long-term direction to daily planning without turning every activity into a goal or reducing progress to one score.

## Ownership boundaries

Phase 11 owns generic goal, system, action, milestone, and learning-path semantics. Phase 08 owns daily scheduling and replanning; Phase 09 owns session execution; Phase 10 owns tracker mechanics; domain phases own academic, development, fitness, routine, language, and money facts. Analytics consumes projections without becoming their source.

## Invariants

1. Goals express direction or outcomes; systems express repeatable practice; actions express executable work.
2. Progress requires evidence appropriate to the owning domain.
3. Safety, sleep, recovery, fixed commitments, and hard constraints filter before priority scoring.
4. Historical plans, evidence, reviews, and definition versions remain auditable.
5. `CORE` works locally and deterministically; intelligence proposes but does not silently commit changes.
6. Pausing, narrowing, maintaining, or retiring a goal can be a valid decision rather than failure.
