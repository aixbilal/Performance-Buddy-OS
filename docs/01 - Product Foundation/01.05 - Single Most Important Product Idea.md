# Single Most Important Product Idea

## Purpose

Identify the central product idea that should guide prioritization when features and domains compete for attention.

## The idea

> **Turn what actually happened into a better next plan.**

The product is not valuable merely because it stores goals, schedules tasks, runs timers, records marks, or draws charts. Its distinctive value comes from closing the loop between intention and reality.

```text
PLAN
↓
ACTION
↓
RESULT
↓
EVIDENCE
↓
ANALYSIS
↓
ADJUSTMENT
↓
NEXT PLAN
```

## Meaning

A plan is a hypothesis about useful action under current knowledge and constraints. Execution produces results. Evidence establishes what can reasonably be concluded. Analysis detects the gap between intended and actual outcomes. Adjustment changes the next plan without rewriting history or treating deviation as moral failure.

## CORE expression

`CORE` can close this loop deterministically through planned-versus-actual reconciliation, completion states, marks, schedules, constraints, session records, and explicit user adjustments. It must already be useful without AI.

## Intelligence expression

`V1` can explain or propose on request. `V2` can identify recurring patterns and friction. `V3` can reason across domains about the highest-value next action. Each remains evidence-aware, validated, explainable, and subject to human decision.

## Prioritization test

A feature should answer at least one of these questions:

- Does it improve the quality or feasibility of a plan?
- Does it make execution easier to begin or record?
- Does it create trustworthy evidence?
- Does it improve analysis or adjustment?
- Does it help the user understand and approve the next plan?

Features that only increase visual complexity, surveillance, or data volume without strengthening the loop have lower priority.
