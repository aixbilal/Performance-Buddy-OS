# Phase 09 — Focus & Session Execution

## Purpose

This phase defines how Performance Buddy OS turns an intention into a safely recorded work session. It owns the shared session lifecycle, timer behavior, notes, interruption handling, and completion evidence. Academic, Development, and Fitness documentation retain ownership of their specialist meaning and safety rules.

## Scope

- planned and unplanned session entry;
- active, paused, interrupted, completing, and saved states;
- session types and domain context;
- timer and note behavior;
- proportionate evidence and honest completion states;
- interruption recovery and AI-off practice.

## Ownership boundaries

Phase 09 owns execution records, not priority calculation, curriculum truth, training prescriptions, or intelligence policy. Phase 08 supplies plans; domain phases supply specialist constraints; analytics consumes immutable session history; intelligence may propose but cannot silently rewrite evidence or completion.

## Invariants

1. Elapsed time alone never proves completion, learning, code quality, or physical performance.
2. Original plans and actual execution remain distinguishable.
3. Meaningful AI-authored changes require explanation and human approval.
4. Sleep, recovery, safety, and fixed commitments remain protected.
5. A session must work offline through deterministic `CORE` behavior.
