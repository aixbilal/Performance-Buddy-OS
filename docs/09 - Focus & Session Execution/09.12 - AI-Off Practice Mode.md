# AI-Off Practice Mode

## Purpose

AI-Off Practice Mode creates deliberate periods in which the user solves, recalls, writes, designs, or codes without generative assistance. It supports independence and honest skill measurement; it is not anti-AI and does not imply surveillance.

## Behavior

When enabled for a session, generative hints, answers, summaries, automatic rewrites, and proactive coaching are unavailable inside the focus surface. Deterministic `CORE` functions remain available: timers, manual notes, checklists, local navigation, evidence capture, and save/recovery.

## Scope and visibility

The mode may apply to the whole session or a declared interval. Its status and scope are always visible. The user may exit early after confirmation; the record notes the change neutrally. The system does not claim it can prevent use of outside tools.

## Deferred assistance

The user may capture questions for later. After the protected interval is completed or ended, the system can offer an explicit review step using an available capability. Later AI output is marked as post-practice assistance and does not alter the original attempt.

## Evidence and analytics

AI-off status is contextual evidence, not proof of mastery or integrity. Analytics may compare self-selected practice modes only with adequate context and must avoid punitive rankings.

## Privacy

Enabling the mode must not increase data collection. Local records follow normal retention and privacy rules.
