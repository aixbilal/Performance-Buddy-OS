# 24.10 — AI Memory Architecture

## Definition

Memory is explicitly governed information reused across AI runs. Conversation history is not automatically memory, and memory is not a new source of truth.

## Memory classes

- **Session:** transient context removed after the run or session window.
- **Preference:** user-approved interaction or planning preference.
- **Fact reference:** pointer to an authoritative domain record, not a duplicate fact.
- **Derived summary:** refreshable synthesis with sources, confidence, and expiry.
- **Proposal:** unapproved candidate that cannot drive action as fact.

## Required metadata

Each item stores owner, purpose, source references, creation method, capability, consent basis, sensitivity, confidence, created/last-used time, expiry, and revocation state. Users can inspect, correct, forget, export, and disable memory.

Sensitive health, money, spiritual, reflection, smoking, nutrition, and similar routine information is not persistently remembered without category- and purpose-specific consent. Sync consent does not imply AI-memory consent. Revocation removes eligible derived indexes and prevents future use.

## Acceptance criteria

- Memory creation is visible and auditable; silent sensitive-memory creation is impossible.
- Stale or contradicted summaries are invalidated or refreshed.
- Disabling memory leaves CORE and stateless assistance usable.
