# Quick Test

## Purpose

Quick Test supports a short, interruption-tolerant review using approved Phase 17 question, source, attempt, scoring, and feedback contracts.

## Flow

The user selects course/topic, source scope, duration or question count, and available difficulty. The test records definition version, question provenance, attempt ID, presented order, responses, timestamps, interruptions, scoring rule, and completion state.

Source-grounded questions remain distinguishable from inferred or generated questions. Offline tests use already available approved content; absence of a remote generator does not relabel invented content as sourced. Auto-scoring is allowed only for deterministic question types. Subjective answers remain unscored or require approved review.

Leaving the app preserves a resumable attempt where policy allows. An abandoned attempt is not scored as completed, and a short result is evidence—not a final declaration of mastery.

## Acceptance criteria

- Attempts survive interruption without duplicate submission.
- Scores remain reproducible from stored definition and responses.
- Weakness feedback cites evidence and preserves source/inference boundaries.
