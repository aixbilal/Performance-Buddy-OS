# Local Database Research

## Decision

Select the local database engine, encryption integration, driver, query/ORM layer, migration tooling, and process/connection topology.

## Mandatory capabilities

ACID transactions, constraints and referential integrity, deterministic queries, indexes, migrations, crash recovery, concurrent readers/safe writer, backup/export consistency, corruption detection, encryption/key support, portability, offline operation, and supported desktop/mobile integration.

## Prototype and tests

Implement representative goals/plans/sessions/trackers, academic attempts/marks, events/outbox, revisions, tombstones, and analytics queries. Test power interruption, disk-full, locking, multiple processes, migration interruption, encryption rotation, backup/restore, corruption, large datasets, query plans, startup, and package/native distribution.

Compare raw/typed queries and ORM trade-offs; convenience cannot hide SQL/schema competence or weaken integrity. Record licenses, binary size, platform constraints, maintenance, and exit/export path.

## Research status

`RESEARCH REQUIRED`: engine, encryption extension/library, driver, ORM/query tool, and migration stack.

## Acceptance criteria

- Tests prove atomic data/revision/audit/event commits.
- Failure never creates an empty replacement silently.
- An ADR documents schema and provider portability.
