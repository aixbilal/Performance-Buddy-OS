# Local Model Research

## Decision

Select local model families, quantizations, runtimes/backends, formats, distribution, and supported hardware tiers per AI application.

## Criteria

Measure structured validity, extraction/classification accuracy, grounding, safety, context/tool support, latency, memory/GPU memory, CPU/GPU utilization, storage, thermal/battery, cancellation, license/distribution, runtime security, model provenance, update cadence, and fallback.

## Benchmark protocol

Freeze application dataset, prompt/schema/tools/policies, runtime/model/quantization, context/batch/threads, hardware/driver/OS, warm/cold state, seeds where available, and evaluation code. Compare against deterministic/no-AI and smaller baselines. Test no-GPU and resource-pressure behavior.

Model files and runtimes receive supply-chain verification. Local execution still requires permissions, minimization, secure caches, and structured validation.

## Research status

`RESEARCH REQUIRED`: no local model/runtime/hardware tier is approved.

## Acceptance criteria

- Critical quality/safety cases pass before speed comparison.
- Unsupported devices degrade clearly without CORE impact.
- The ADR defines download, update, removal, and license obligations.
