# Embedding Model Research

## Decision

Select local and, if separately approved, remote embedding models for specific retrieval corpora and languages.

## Criteria

Evaluate retrieval quality, dimensions, context/token limits, language coverage including German/Italian, code/academic text, latency, throughput, memory/storage, batching, model/license/provenance, quantization, determinism, privacy/region/retention for remote use, cost, and index migration.

## Evaluation

Use versioned queries, relevant sources/chunks, hard negatives, permission zones, renamed/deleted sources, source conflicts, and exact parser/chunker generations. Measure recall/precision/ranking, no-result correctness, leakage, latency, and storage. Compare lexical/no-embedding baselines.

Mixed model generations are separate vector spaces. A model change creates a new index generation and controlled rebuild. Similarity is not truth; results cite sources.

## Research status

`RESEARCH REQUIRED`: no model, dimensions, chunking, or remote provider is approved.

## Acceptance criteria

- Permission and revocation tests have zero prohibited retrieval.
- Quality improvement justifies resource/privacy cost over lexical search.
- The ADR defines rebuild and model-exit behavior.
