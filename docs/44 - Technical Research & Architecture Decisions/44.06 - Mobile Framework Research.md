# Mobile Framework Research

## Decision

Select native or cross-platform mobile framework, secure storage, local database adapter, background transfer, notifications, and release tooling only after MOBILE promotion readiness.

## Criteria

Compare OS/device support, accessibility and scalable text, secure storage/biometrics, offline database/migrations, background/suspension behavior, sync, notifications/deep links, camera/microphone/files, encryption, performance/battery/startup/package, testing/debugging, ecosystem/security, store compliance, developer learning, native escape hatches, and exit risk.

## Prototypes

Test airplane-mode captures, interrupted draft, migration, camera/OCR draft, session across background/termination, notification action, encrypted sync conflict, revoked device, deep link, large text/screen reader, low storage, and store-signed update on each proposed platform.

Code sharing is a benefit only when it preserves platform quality and shared domain contracts.

## Research status

`RESEARCH REQUIRED`: framework, libraries, support matrix, signing/stores, and release pipeline. Mobile remains optional/deferred.

## Acceptance criteria

- Finalists run equivalent risk-focused device tests.
- Offline/security/accessibility blockers outweigh reuse.
- The ADR defines independent desktop/mobile version compatibility.
