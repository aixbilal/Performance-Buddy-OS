# Cloud Provider Research

## Decision

Evaluate optional cloud infrastructure for sync, identity, storage, jobs, observability, and backup without making CORE remote-dependent.

## Criteria

Compare security/tenant isolation, encryption/key control, privacy/data use/subprocessors, residency, retention/deletion/export, identity/device authorization, consistency/transactions/change feeds, object storage, quotas/rates, availability/durability/incidents, observability/support, local development/testing, infrastructure portability, compliance needs, pricing/egress, lock-in, and provider exit.

## Evidence

Use current primary documentation, contractual terms, status/incident history, certifications with scope, and a dated cost model. Marketing claims require verification. Include explicit no-cloud and self-hosted comparisons where feasible.

Prototype tenant isolation, auth/revocation, encrypted data, failure/quota, export/delete, backup/restore, provider outage, and migration.

## Research status

`RESEARCH REQUIRED`: no provider, region, service, identity, or key system is approved.

## Acceptance criteria

- Threat, privacy, cost, failure, and exit evidence are complete.
- Provider loss cannot invalidate canonical local records.
- The ADR includes review triggers for terms, price, and availability changes.
