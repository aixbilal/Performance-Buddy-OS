# Charting Library Research

## Decision

Select a charting approach for academic, trend, time-allocation, fitness, routine, money, and cross-domain analytics while preserving accessible data alternatives.

## Criteria

Compare chart types needed, semantic accessibility, keyboard exploration, text/table equivalents, screen-reader output, responsive/large-monitor behavior, high contrast, color independence, reduced motion, localization, timezones, uncertainty/missing data, large datasets, interaction, export, bundle/performance, theming, testing, maintenance/security, licensing, and escape hatches.

## Prototype

Build grade projection with assumptions, plan-vs-reality timeline, trend with gaps/uncertainty, stacked time allocation, fitness load/recovery, and accessible table alternatives. Test zoom, keyboard, tooltip/focus, resize, print/export, long labels, and empty/error states.

Charts never replace exact values or source/version explanations. Decorative animation cannot obscure changes.

## Research status

`RESEARCH REQUIRED`: no library or rendering approach is approved.

## Acceptance criteria

- Every visualization has an equivalent understandable nonvisual path.
- Performance meets realistic data budgets.
- The ADR records export, accessibility, and lock-in limitations.
