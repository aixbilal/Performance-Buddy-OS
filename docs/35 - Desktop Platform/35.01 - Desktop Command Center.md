# Desktop Command Center

## Role

The desktop application is the primary deep-work and management surface. It combines stable primary navigation, a context header, the active workspace, optional supporting panels, and global utilities for search, command palette, capture, notifications, help, and settings.

## Core experience

Today, planning, focus sessions, goals, academic work, knowledge, development, fitness, routines, money, analytics, and approved AI proposals use the same canonical domain contracts. The shell may optimize layout, but it cannot redefine calculations, evidence, permissions, or statuses.

Desktop navigation preserves route, selection, safe filters, scroll, and focus through back/forward movement. Optional panels add context without creating a second authoritative editor. Offline, background, sync, indexing, and AI state appear at the smallest relevant scope.

## Interaction priorities

Frequent work is keyboard-efficient, large-monitor space provides useful context, and focus sessions survive navigation. Capture remains fast without converting incomplete input into false completion or evidence.

## Acceptance criteria

- Core workflows remain understandable with AI and cloud disabled.
- Navigation and session state survive safe route changes and restart where specified.
- No pointer-only path blocks a primary workflow.
