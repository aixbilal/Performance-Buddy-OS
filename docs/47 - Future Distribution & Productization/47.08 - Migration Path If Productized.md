# Migration Path If Productized

## Principle

Productization, if approved, proceeds through reversible evidence-gated stages. The personal installation is not silently converted into a hosted account, and existing local data is never uploaded merely because distribution becomes available.

## Staged path

1. **Prove personal value:** stable CORE workflows, understood architecture, tests, backup/restore, and real owner use.
2. **Prepare distribution:** licensing and dependency review, reproducible builds, signing, packaging, updates, documentation, synthetic demos, and support boundaries.
3. **Validate portability:** versioned export/import, schema migration, provenance, local backup, corruption recovery, and compatibility evidence.
4. **Pilot local single-user distribution:** explicit support scope, privacy-safe diagnostics, update rollback, and no required account.
5. **Research optional hosted capabilities:** threat model, legal/privacy review, cost, identity, synchronization, deletion, incident, and exit design.
6. **Pilot with consent:** isolated synthetic then limited user data, explicit opt-in, migration preview, reconciliation, rollback, and monitoring.
7. **Consider multi-user operation:** only after separate Phase 02 promotion, ADRs, isolation tests, operational readiness, and accountable approval.

## Data migration contract

Inventory and checksum the source; back it up; map every entity, revision, provenance record, permission, and deletion state; dry-run into a candidate target; validate counts and deterministic results; preview differences; obtain explicit consent; commit transactionally; retain reconciliation evidence; and provide rollback or export when technically possible.

## Acceptance criteria

- Every stage has independent entry, exit, rollback, and evidence criteria.
- Local-only users are not forced to enroll or migrate.
- No populated field, permission, provenance link, or deletion state is silently lost.
- Productization claims begin only after the corresponding operational capability is proven.
