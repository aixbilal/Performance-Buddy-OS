# Retrieval Evaluation

## Scope

Evaluate lexical, metadata, graph, and embedding retrieval using authorized sources and permission-aware queries. Separate retrieval relevance from generated-answer quality.

## Dataset and metrics

Version queries, expected relevant sources/chunks, hard negatives, source revisions, permissions, language, and freshness. Include exact facts, paraphrases, multi-hop relationships, ambiguous course codes, renamed/moved notes, deleted/revoked files, German/Italian material, and prompt-injected content.

Measure recall/precision at K, ranking quality, no-result correctness, citation location accuracy, freshness, latency, index coverage, duplicate rate, permission leakage, and sensitivity to chunk/model generation. Compare lexical and semantic baselines; similarity is not truth.

Indexes are disposable projections. Parser/chunker/embedding/model changes create distinct generations and rerun evaluation. Results must identify the authorized source and location; inaccessible filenames/snippets cannot leak.

## Acceptance criteria

- Revoked, deleted, local-only, and never-AI sources are absent from prohibited results.
- Hard-negative and source-conflict cases do not become confident answers.
- Thresholds are defined per application and consequence before promotion.
