# Adaptive Planning Tests

## Scope

Test daily planning, plan/reality reconciliation, protected constraints, fixed/flexible commitments, priority calculations, schedule feasibility, mode changes, university-day updates, evening replanning, recovery mode, and day closure.

## Scenario matrix

Include normal, midterm, terminal, weekend, recovery, missed class, new deadline, weak topic, ahead/behind development path, hard workout, poor sleep, language maintenance, travel, interruption, limited capacity, and conflicting goals. Use controlled clocks/timezones and immutable fact snapshots.

Assertions verify sleep and fixed commitments remain protected, time is not double-booked, completed evidence is preserved, unverified facts do not drive hard changes, deferred items remain visible, and explanations cite inputs, rules, trade-offs, and plan revision.

Metamorphic tests check that reducing available time cannot increase scheduled load without explicit displacement, and adding a protected commitment cannot be ignored. AI proposals are revalidated by CORE.

## Acceptance criteria

- Identical snapshots and versions yield identical deterministic plans.
- Infeasible input produces explainable conflict, not fabricated feasibility.
- Replanning never rewrites history or marks deferred work failed automatically.
