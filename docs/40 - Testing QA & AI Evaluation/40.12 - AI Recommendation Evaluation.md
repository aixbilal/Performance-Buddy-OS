# AI Recommendation Evaluation

## Dimensions

Evaluate recommendations for evidence relevance, factual correctness, constraint compliance, feasibility, expected value, prioritization, personalization within permission, explanation fidelity, uncertainty calibration, actionability, stability, novelty, non-manipulation, and user control.

## Dataset

Use versioned scenario sets across academics, development, fitness/recovery, routines/language, money boundaries, cross-domain conflicts, sparse data, stale data, contradictory evidence, exam pressure, and rejection history. Define gold constraints and acceptable action sets; do not force one wording as the only correct answer.

Combine deterministic checks, blinded human rubric review, pairwise comparison, calibration analysis, and later outcome analysis. Outcome correlations do not prove causality. User acceptance is not proof of safety or correctness.

Record model, prompt, policies, tools, retrieval, context, provider, dataset, reviewer, and threshold versions. Compare against deterministic/no-AI and simpler baselines.

## Acceptance criteria

- Protected-constraint violation or unsupported consequential fact is a critical failure.
- Claimed reasons match the evidence actually used.
- Promotion requires value above baseline without safety/privacy regression.
