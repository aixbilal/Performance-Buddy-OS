# 40.20 - Multi-Agent Coordination Tests
## Coverage

Test single and multi-specialist flows, direct companion requests, bounded parallelism, ordering, cancellation, retries, duplicate messages, loop limits, checkpoint recovery, and Head Coach synthesis. Scenarios include specialist disagreement, contradictory evidence, missing specialist, stale context, and academic/development/recovery proposals that form an impossible combined schedule.

Security cases attempt permission leakage across domains, derived summaries, logs, tool calls, retries, and provider fallback. Structured-output cases inject malformed, truncated, schema-valid-but-semantic-invalid, and adversarial messages. No invalid finding may be treated as evidence.

## Pass criteria

- Exactly one synthesis reaches deterministic validation and user review.
- Rule rejection is visible and drives revision or safe non-resolution.
- Dissent/provenance survives synthesis; agents cannot escalate tools or memory scope.
- Fallback never fabricates missing specialist agreement.
