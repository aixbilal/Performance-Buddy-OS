# 40.21 - Provider Failover Tests
## Matrix

Exercise local model, configured Gemini endpoints/projects, Groq, deterministic fallback, and test doubles across authentication failure, permission denial, timeout, outage, rate limit, malformed structured output, capability mismatch, refusal, cancellation, and partial streaming.

Assert bounded retries, idempotency, normalized errors, routing audit, privacy eligibility, disclosure, latency/budget limits, and unchanged agent identity. Simulate provider removal and credential rotation. Verify routing does not rotate credentials to evade quota or terms.

## Pass criteria

- Local-only data never leaves the device during failover.
- Consequential output is schema-, semantic-, rule-, and approval-validated after fallback.
- Provider exhaustion yields safe degraded behavior while deterministic core stays available.
- No failed attempt duplicates writes or loses correlation/provenance.
