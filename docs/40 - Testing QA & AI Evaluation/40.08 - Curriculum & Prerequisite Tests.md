# Curriculum & Prerequisite Tests

## Curriculum fixtures

Use versioned synthetic and authorized curriculum fixtures covering programs, cohorts, campuses, semesters, credits, electives, substitutions, retired courses, repeats, transfers, and effective-date changes. Imported official candidates retain source and applicability.

## Graph tests

Verify node/edge identity, directed prerequisite meaning, AND/OR groups if approved, co-requisites, minimum-grade conditions, transitive dependencies, cycle detection, missing nodes, duplicate edges, version differences, and topological queries. Property tests ensure traversal termination and deterministic results.

Risk analysis tests distinguish factual prerequisite blockage from projections and uncertainty. Passed/failed/repeated attempts use the correct curriculum and policy versions. A newer catalog cannot silently rewrite a historical cohort.

Import tests cover ambiguous course matches, code reuse, source conflict, stale documents, partial extraction, and no silent dropping. AI/OCR remains candidate generation only.

## Acceptance criteria

- Every risk result cites graph edges, attempt evidence, and applicable version.
- Cycles and unresolved applicability produce visible blocked states.
- Curriculum migration reconciles counts, identities, and prerequisite results.
