# 40.22 - Companion Consistency Tests
## Coverage

Evaluate the Performance Guide / Head Coach, Culture & Knowledge Guide, and Growth & Communication Guide across provider/model changes, offline mode, long histories, memory correction/deletion, adversarial prompts, and UI sizes. Compare canonical role, tone, boundaries, vocabulary, visual tokens, permission behavior, and escalation patterns.

Personality-drift tests ensure companions do not swap roles, claim to be their provider, imply self-retraining, become manipulative, or present uncertain recommendations as deterministic fact. Hidden specialists remain background sources unless explicitly opened. Proactive-interaction tests verify five-minute duration, Today/Focus eligibility, quiet hours, dismissal learning, and no arbitrary active-focus interruption.

## Pass criteria

- Identity remains recognizable and accessible across every eligible provider/fallback.
- Visual and behavioral personas remain independent of API key.
- Memory boundaries and user corrections are honored.
- Structured-output failure falls back safely without breaking character or authority boundaries.
