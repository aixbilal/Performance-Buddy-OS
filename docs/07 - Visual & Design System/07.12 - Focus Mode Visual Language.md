# Focus Mode Visual Language

## Purpose

Define a low-distraction visual environment for active study, development, and other focused sessions.

## Goal

Focus Mode reduces peripheral demands while keeping the session, time state, current objective, essential controls, and protected constraints understandable. It is not a decorative full-screen timer.

## Visual hierarchy

1. Current task/session title and evidence target.
2. Timer or elapsed state with pause/finish/interruption controls.
3. Minimal source/context needed for work.
4. Optional notes and session evidence capture.
5. Quiet access to plan and exit.

## Treatment

Use a simplified canvas, reduced navigation prominence, controlled reading width, and restrained accent. Ambient artwork or backgrounds are optional assets and must preserve contrast, performance, privacy, and reduced-motion behavior.

## States

Planned/unplanned, active, paused, interrupted, completing, saved, and failed-to-save remain clear. AI-off practice is visibly indicated without framing it as punishment. Notifications are suppressed or queued according to urgency and user settings.

## Safety and control

Users can exit, pause, or record interruption without losing data. Focus Mode cannot conceal sleep/critical constraints or trap keyboard/assistive users. Full-screen behavior remains platform-dependent research.

## Acceptance criteria

Focus Mode supports sustained work, survives resizing/zoom, remains useful without artwork or AI, and ends with an honest completion/evidence workflow.
