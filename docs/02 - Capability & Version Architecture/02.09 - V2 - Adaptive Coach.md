# V2 — Adaptive Coach

## Purpose

Define evidence-based historical analysis that identifies patterns, friction, risks, and possible adjustments without autonomous control.

## Scope

V2 analyzes approved historical windows across relevant domains. It may identify repeated schedule friction, workload imbalance, study effectiveness signals, recovery concerns, neglected skills, and potential academic risk, then propose adaptations.

## Evidence contract

Every material finding identifies time window, data coverage, relevant observations, missing data, inference level, competing explanations, and confidence. Correlation is not presented as causation. Sparse or biased records reduce confidence rather than producing stronger narrative.

## Recommendation contract

Recommendations state proposed change, expected benefit, trade-offs, protected constraints, reason codes, and review date. Deterministic rules validate feasibility; the human accepts, edits, rejects, or defers. Outcomes are recorded so later analysis can learn whether advice helped.

## Boundaries

V2 does not diagnose health, moralize consistency, modify plans silently, or optimize one domain by sacrificing protected sleep/recovery. Money remains separate from an overall performance score.

## Readiness

V2 requires stable evidence semantics, sufficient history, reliable V1 approval workflows, evaluation datasets, and false-positive monitoring. It is not part of initial CORE.

## Acceptance criteria

Findings are reproducible from cited evidence; uncertainty is calibrated; recommendations survive rule validation; user decisions are honored; and evaluation shows useful signal beyond deterministic analytics.
