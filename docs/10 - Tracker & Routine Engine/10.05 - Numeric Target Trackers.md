# Numeric Target Trackers

## Purpose

A Numeric Target tracker records a measurable value compared with a goal, range, minimum, maximum, or directional target. It supports values such as distance, load, sleep duration, savings contribution, or other owner-approved measurements.

## Definition

The definition declares numeric precision, unit, target operator, target value or range, valid bounds, aggregation method, and source policy. Changing unit, operator, or target creates a new effective definition version.

## Validation and meaning

`CORE` validates numeric form, unit compatibility, bounds, and definition version. Target satisfaction is a deterministic comparison, not necessarily task completion. For a maximum limit, lower may be favorable; for a range, both bounds matter. No universal “more is better” assumption is allowed.

## Missing and uncertain values

Zero, unknown, estimated, and not applicable are distinct. Estimated or imported values carry confidence and provenance. Conversion uses an identified conversion rule and retains original input.

## Safety boundary

Targets involving fitness, sleep, nutrition, health, academics, or money remain governed by their owner domains. The tracker must not encourage unsafe behavior to reach a number.

## Acceptance criteria

Comparisons are reproducible and explainable, units never combine silently, definition changes preserve history, and target attainment is not overstated.
