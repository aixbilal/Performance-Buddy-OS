# 30.19 - Agent Memory Access Scopes
## Scope model

Memory access is granted by agent, purpose, domain, field/classification, operation (`read`, `propose`, `append-approved`, `forget-request`), locality, and expiry. Default is no access. The Head Coach may coordinate broader references but does not automatically receive unrestricted raw data.

Persistent companions have distinct approved preference/continuity scopes. Hidden specialists receive task-scoped leases and only the minimum needed context. Provider adapters never obtain standing memory permissions; they receive one validated request package.

Deterministic facts cannot be overwritten by memory. Proposed corrections follow domain validation and approval. Access, denial, provenance, retention, and deletion are auditable with sensitive content redacted.

## Acceptance criteria

- Scope expansion requires explicit policy/approval, never agent request alone.
- Expired specialist leases stop retrieval immediately.
- Users can inspect and revoke companion memory access.
- Tests prove domain isolation and derived-summary inheritance.
