# 30.18 - Inter-Agent Data Sharing Policy
## Policy

Inter-agent sharing is purpose-bound, least-privilege, and denied by default. The orchestrator evaluates source classification, requesting and receiving agent scopes, task purpose, user consent, provider locality, retention, and field-level minimization before building a context envelope.

Never-AI data is never shared. Local-only data stays on-device. Ask-every-time data requires current consent before any eligible remote transmission. Credentials and secret values are never agent context. Specialists receive references or redacted summaries when full records are unnecessary.

Sharing records capture who, why, which fields/classes, provider locality, decision, expiry, and redaction—not sensitive values in plaintext audit. Derived summaries inherit the strictest source classification.

## Acceptance criteria

- Cross-domain and remote sharing fail closed when policy is missing or ambiguous.
- Revocation blocks new access and triggers retention cleanup where supported.
- Permission-leakage tests cover prompts, messages, logs, caches, retries, and fallbacks.
