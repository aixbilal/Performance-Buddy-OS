# 30.09 — Cloud AI Disclosure

## Principle

Remote AI use is optional, visible, and purpose-specific. Cloud processing never occurs as a hidden fallback from local failure.

## Required disclosure

Before first use and whenever materially changed, show feature/purpose; selected data categories and scope; provider and processing location/region when known; transformations; retention/training controls when known; memory behavior; cost implications; expected benefit/limitations; alternatives; and revocation/deletion route.

## Rules

Sync, backup, account sign-in, general AI enablement, or provider selection does not authorize a data transfer. Context is minimized before transfer and exposure is recorded by references/categories rather than duplicated content. Unknown provider retention or regional behavior is disclosed as unknown and may block sensitive use.

Provider/model switching rechecks consent if destination, exposure, quality, or cost changes. Local preprocessing does not make a remote request “local.”

## Acceptance criteria

- Network traces match disclosed destination and minimum payload contract.
- Consent/denial/revocation tests cover provider changes, retries, failover, and background runs.
- Cloud outage or denial preserves local/CORE workflows and trusted data.
