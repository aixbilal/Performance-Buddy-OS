# 30.07 — Ask-Every-Time Data

## Definition

Ask-every-time data requires a fresh contextual consent decision for each AI run or clearly bounded continuation. Prior use, sync, memory, provider approval, or another category's consent cannot satisfy it.

## Recommended categories

Detailed prayer/exception information, reflection text, smoking triggers, nutrition detail, health-adjacent symptoms, skincare photos/reactions, voice recordings, financial transaction detail, private support notes, and user-designated sensitive sources should default here unless set to stricter never-AI.

## Consent prompt

Show application purpose, exact categories/source scope, requested fields or summaries, local/cloud location, provider where remote, retention/memory, expected output, expiration, and alternatives. No preselection, bundling, or dark patterns. The user may reduce scope or continue without AI.

Consent is re-requested after purpose, provider, location, category, retention, or material scope changes. Denial produces no access and is not repeatedly pressured during the run.

## Acceptance criteria

- Cached tokens cannot authorize a later run or expanded scope.
- Tests cover resume, retry, specialist, background, and provider-switch consent.
- Audit records the decision without copying sensitive content.
