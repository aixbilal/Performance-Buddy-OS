# 26.02 — V1 Non-Goals

## Excluded behavior

V1 does not:

- monitor the user continuously or initiate coaching without a request;
- learn behavioral patterns across history, predict risk, or autonomously adapt plans (`V2`);
- perform long-horizon cross-domain optimization or claim a highest-value next action (`V3`);
- silently create, edit, reschedule, complete, delete, send, purchase, or publish anything;
- replace CORE arithmetic, official sources, domain policies, or protected constraints;
- diagnose health conditions, prescribe treatment, or provide professional financial advice;
- access private routine, financial, health, vault, or other sensitive categories without scoped permission;
- persist memory merely because information appeared in chat;
- train provider or local models on personal data through an implied product workflow;
- guarantee correctness, learning outcomes, grades, fitness results, or optimal schedules.

## Boundary response

When asked for excluded behavior, V1 explains the boundary and offers a safe read, draft, deterministic tool, manual workflow, or clearly labeled future capability. It must not simulate V2/V3 behavior under a V1 label.

## Acceptance criteria

- Tests cover autonomous-action requests, unsafe advice, hidden-memory requests, and capability overreach.
- Refusal preserves helpful in-scope assistance where possible.
- No prompt, provider option, or tool path can silently expand V1 authority.
