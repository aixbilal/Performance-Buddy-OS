# 26.11 — Test Generation

## Scope

V1 may generate draft practice questions from a user-selected course, topic, difficulty, format, duration/item count, assistance mode, and permissioned source set. Phase 17 owns test entities, attempts, scoring, weakness feedback, and past-paper boundaries.

## Pipeline

Validate permissions and source coverage; retrieve bounded passages; generate typed candidate items; attach source references and answer rationale; check schema, scope, duplication, ambiguity, solvability, difficulty intent, source entailment, and answer leakage; then preview limitations and freeze an immutable test version when accepted.

CORE may assemble reviewed question-bank items without AI. AI-generated items are labeled and remain drafts until required validation and human review. Unsupported coverage yields fewer questions or a gap report, not invented facts. Answer keys remain separated from the active attempt surface.

V1 does not use longitudinal weakness detection to choose content unless the user explicitly supplies current targets; automatic historical adaptation belongs to V2.

## Acceptance criteria

- Generated tests preserve source provenance and identify AI-generated items.
- Tests cover duplicates, invalid questions, conflicting sources, leakage, and insufficient coverage.
- Provider failure leaves existing tests/attempts unchanged and offers reviewed-bank or manual alternatives.
