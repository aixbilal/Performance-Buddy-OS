# 26.01 — V1 Scope

## Capability statement

V1 is a user-initiated assistant for bounded, task-level help. It can interpret a request, retrieve permitted context, invoke allowlisted read or deterministic compute tools, explain results, tutor from sources, generate draft practice material, and propose changes for approval.

## Included capabilities

- natural-language navigation and registered commands;
- read-only questions about current plans, trackers, academics, knowledge, development, fitness, routines, and money within permission boundaries;
- explanations of CORE calculations and validation outcomes;
- source-grounded tutoring and practice-test drafts;
- proposals to create or modify habits, actions, plans, schedules, and records;
- clarification when intent, entity, time, or consequence is ambiguous.

## Trigger and context

The trigger is an explicit user request. V1 receives only task-relevant context and does not continuously analyze history. It may use `LOCAL` or approved `CLOUD` inference through Phase 24, with the execution location disclosed where relevant.

## Output classes

Outputs are `ANSWER`, `CORE_RESULT_EXPLANATION`, `DRAFT`, `PROPOSAL`, `CLARIFICATION`, `REFUSAL`, or `UNAVAILABLE`. A proposal is not an action.

## Acceptance criteria

- Every feature maps to an allowed output class, tools, data scope, and fallback.
- V1 never requires `V2` historical pattern detection or `V3` cross-domain optimization.
- Disabling V1 preserves access to all committed CORE workflows and records.
