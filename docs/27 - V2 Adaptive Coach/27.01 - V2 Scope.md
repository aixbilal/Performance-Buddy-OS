# 27.01 — V2 Scope

## Capability statement

V2 analyzes user-authorized historical evidence windows to detect repeated conditions and propose bounded adaptations. Triggers may be an explicit user request or a separately enabled scheduled analysis run.

## Included capabilities

- historical comparisons across compatible periods and modes;
- repeated-pattern and behavioral-friction candidates;
- study-effectiveness and workload analysis;
- predictive risk signals expressed as uncertain review prompts;
- carefully scoped cross-domain correlations;
- adaptive schedule proposals validated by CORE;
- recommendation memory and outcome analysis;
- scheduled summaries and proposal generation.

## Preconditions

Stable evidence semantics, sufficient coverage, permission-safe analytics, reliable V1 approval, versioned analysis methods, false-positive monitoring, and Phase 24 evaluation gates are required. V2 is optional and not part of CORE.

## Output classes

Outputs are `FINDING`, `PATTERN_CANDIDATE`, `FRICTION_CANDIDATE`, `RISK_SIGNAL`, `ADAPTIVE_PROPOSAL`, `INSUFFICIENT_EVIDENCE`, or `NO_MATERIAL_FINDING`. Silence or missing data is not evidence of success or failure.

## Acceptance criteria

- Each feature declares inputs, minimum evidence, method, output, consequence, and fallback.
- V2 cannot silently perform V3 cross-domain optimization or autonomous action.
- User controls can disable analysis by feature, domain, schedule, and data category.
