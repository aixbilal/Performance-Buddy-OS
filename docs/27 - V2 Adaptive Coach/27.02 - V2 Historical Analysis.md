# 27.02 — V2 Historical Analysis

## Purpose

Transform approved event and evidence history into traceable observations without rewriting source records or overstating what the history proves.

## Analysis manifest

Each run records purpose, domains, source IDs/revisions, eligibility filters, window, timezone, mode segmentation, metric/rule versions, missingness, exclusions, privacy policy, analysis version, and generated findings. Derived results link to source evidence and expire when material inputs change.

## Method

Normalize timestamps and units; deduplicate events; preserve rest, excused, partial, and unknown states; compute deterministic measures through Phase 22/CORE; assess coverage and bias; compare compatible periods; then allow V2 interpretation. Planned, active, completed, and evidenced work remain distinct.

Historical data may reflect logging behavior, calendar changes, exams, illness, travel, or device gaps. These possible confounders remain visible. The assistant must not turn incomplete diaries into confident personal narratives.

## Acceptance criteria

- A finding can be reproduced from its frozen analysis manifest and source revisions.
- Corrections, deletions, permission changes, and late events invalidate affected derived results.
- Low coverage yields a gap report or abstention rather than a stronger story.
