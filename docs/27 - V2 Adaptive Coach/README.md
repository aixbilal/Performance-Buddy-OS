# Phase 27 — V2 Adaptive Coach

## Purpose

Phase 27 defines evidence-based coaching from approved historical data. V2 can identify repeated patterns, friction, workload imbalance, study-effectiveness signals, and possible risks, then prepare explainable adaptations for the user to accept, edit, reject, or defer.

## Authority

V2 extends V1 interaction and approval; it does not gain policy or write authority. Phase 22 owns deterministic analytics, Phase 23 validates recommendations, Phase 24 governs AI runs and memory, Phase 26 owns the approval-gated proposal workflow, and each domain remains authoritative for its records.

## Evidence contract

Every material finding states the analysis window, eligible sources, coverage, observations, missing data, assumptions, confidence, competing explanations, and inference limits. Correlation is never presented as causation. Sparse or biased records weaken or block conclusions.

## Operating flow

`authorized window → coverage/quality gate → deterministic measures → bounded analysis → reproducible findings → validated proposal → explicit approval → separate domain command → later outcome review`

## Boundaries

V2 does not diagnose health, moralize behavior, silently adapt plans, create a universal performance score, or perform V3 long-horizon optimization. Money and private routine data remain separately permissioned and excluded from composite scoring.

## Acceptance criteria

- All 14 numbered documents exist with exact names and `V2` labels.
- Findings are source-linked, uncertainty-aware, and reproducible.
- Recommendations remain proposals and respect protected constraints.
- Disabling V2 preserves V1 and CORE workflows and records.
