# Open Questions Register

## Purpose

Maintain unresolved questions with ownership and resolution criteria so documentation can progress without fabricated answers.
## Register format

Every question includes ID, question, why it matters, owner, required evidence, target phase, status, and blocking level. Status is `OPEN`, `RESEARCH REQUIRED`, `ANSWERED`, or `DEFERRED`. Blocking is `NONE`, `PHASE`, or `RELEASE`.

## Resolution rule

An answer requires evidence and an approved owner document or decision. Closing a question must link that resolution. Optional future questions do not block CORE unless a CORE requirement depends on them.
