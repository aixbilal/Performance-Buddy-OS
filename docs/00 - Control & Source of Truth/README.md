# Phase 00 — Control & Source of Truth

## Purpose

Establish the governance system that every Performance Buddy OS document, design, implementation decision, and AI-assisted contribution must follow.
## Phase role

Phase 00 is the control plane for project knowledge. It defines authority, terminology, metadata, lifecycle states, conflict handling, change control, and the reading order for people and coding agents. It does not define detailed product behavior; later phases own those details under these rules.

## Governing principles

- The locked root blueprint controls paths and filenames.
- Verified evidence outranks interpretation; interpretation never becomes fact without approval.
- Product behavior is personal-first, desktop-first, and offline-first at `CORE`.
- AI proposes, deterministic rules validate, and the human decides meaningful changes.
- Deterministic mathematics, including academic calculations, is never delegated to an LLM.
- Protected constraints, privacy permissions, explainability, and calm language are mandatory.
- `LOCAL`, `V1`, `V2`, `V3`, `CLOUD`, `MOBILE`, and `FUTURE` must not be presented as initial `CORE` behavior.

## Phase acceptance criteria

Phase 00 is valid when all 20 locked files exist, their metadata and terms agree, no provisional choice is presented as approved, the root blueprint remains unchanged, and later contributors can determine what is authoritative and how to resolve uncertainty.
