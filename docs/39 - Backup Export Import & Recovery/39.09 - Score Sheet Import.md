# Score Sheet Import

## Status and purpose

No approved legacy score-sheet artifact is assumed. This document defines the controlled migration required when one is supplied.

## Inventory

Before mapping, preserve the original read-only and record checksum, workbook/file version, sheets and ranges, tables, formulas, named cells, hidden rows/columns, external links, macros, manual overrides, precision, rounding, formatting-dependent meaning, policy assumptions, sample outputs, and sensitive identifiers. Macros and links are never executed.

## Reconciliation

Map curriculum/course identity and attempts to Phase 12; assessments, marks, schemes, grades, repeat decisions, SGPA/CGPA, and scenarios to Phase 13. Formatting is not semantics. Formula logic is prior evidence, not official policy; hidden or undocumented constants remain `UNRESOLVED`.

Import into an isolated candidate workspace, account for every populated field, recompute independently using approved policy, compare cell-level and aggregate outputs, explain discrepancies, and obtain approval. Mapping decisions and importer version make replay idempotent.

## Acceptance criteria

- No populated source field is silently dropped.
- Every formula maps, is retired explicitly, or remains blocked.
- Discrepancies cannot be accepted through rounding or display coincidence alone.
