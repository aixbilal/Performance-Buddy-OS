# Academic Data Import

## Scope

Academic import handles transcripts, registrations, schedules, curriculum candidates, course attempts, and other personal records as sensitive evidence. Personal records do not establish institution-wide CUI policy.

## Mapping

Capture owner, issuer/source class, document type, version/effective date, retrieval/import time, checksum, privacy, and permission. Extract candidates for student identity only where necessary, program/cohort, term, course code/title, credits, attempt, enrollment/status, marks/grade, and source references.

Match against versioned Phase 12/13 entities using course, term, attempt, curriculum, and applicable-policy context. Ambiguous matches remain quarantined. Official-source authenticity and applicability require human verification; OCR or AI extraction cannot promote facts independently.

The preview shows raw/normalized values, duplicates, conflicts, policy gaps, calculations affected, and fields excluded. Corrections preserve prior sources and revisions. Cloud/AI processing requires scoped permission and redaction.

## Acceptance criteria

- Imported evidence never invents general curriculum or grading rules.
- Every published record is traceable to source and mapping decision.
- Ambiguity blocks only affected candidates, leaving approved data intact.
