# 32.09 — Academic Schema

## Entities

`University`, `Program`, `StudentProgramEnrollment`, `AcademicTerm`, `CourseEnrollment`, `CourseAttempt`, and status-history records. Each separates official definition from personal enrollment/record, with source, applicability, verification, effective dates, and privacy.

## Invariants

Programs are scoped by university/campus/cohort/delivery dimensions when relevant. Attempts are immutable identities; repeat/grade policy determines inclusion, not destructive replacement. Enrollment state changes append history. Sensitive student identifiers are minimized and never routine display keys.

## Acceptance criteria

- Historical programs/terms/attempts coexist without overwriting official definitions.
- Unknown campus/cohort/applicability remains explicit.
- Academic records can link curricula and assessments while preserving their owners.
