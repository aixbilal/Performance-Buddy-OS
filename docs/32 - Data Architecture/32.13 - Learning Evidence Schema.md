# 32.13 — Learning Evidence Schema

## Entity

`LearningEvidence`: knowledge ID, evidence type, source entity/ref, observed outcome, verified correctness/quality, assistance/independence mode, context, occurred/recorded times, freshness, verification state, privacy, revision, and relation (`supports`, `contradicts`, `neutral`).

## Types

Exposure, study activity, self-explanation, retrieval attempt, worked problem, application/project, assignment, practice test, official assessment, feedback, and correction remain distinct. Duration is metadata, not strength by itself.

## Invariants

Deduplicate by source event/revision. AI-generated material is not evidence of user learning. Corrections invalidate dependent confidence projections. Confidence is a disposable derived record with method/input versions.

## Acceptance criteria

- Every confidence input is sourced, typed, permissioned, and inspectable.
- Assisted and independent evidence cannot be silently merged.
- Missing evidence remains unknown.
