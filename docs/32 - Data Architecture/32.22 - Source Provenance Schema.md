# 32.22 — Source Provenance Schema

## Entities

`SourceRecord`: source type, authority class, owner/custodian, title/URI/path reference, version/checksum, effective/published/retrieved times, access/permission, verification, privacy/data zone. `DerivationRecord`: output entity/revision, method/rule/model/parser/index versions, input source/entity revisions, transformations, confidence, created time, and invalidation state.

## Rules

Hashes support integrity, not factual truth. Source conflict follows Phase 00. Raw external values and normalized values remain linked. Provenance inherits sensitivity and cannot leak inaccessible filenames/snippets. Deletion/revocation propagates invalidation through derivation links.

## Acceptance criteria

- Every consequential derived result resolves to inputs and versions.
- Lineage queries find all dependents of a corrected/deleted source.
- Citation and permission checks use the same canonical provenance.
