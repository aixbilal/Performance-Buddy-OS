# 32.15 — Fitness Schema

## Entities

`TrainingPlan`, `WorkoutSession`, `ExerciseSet/Interval`, `ActivityMetric`, `TrainingLoadRecord`, `RecoverySignal`, `RecoverySession`, and `RestDay`. Fields include activity type, prescribed/actual work, units, intensity context, source/device, occurred time, confidence, privacy, and revision.

## Invariants

Raw device/self-report values remain separate from normalized/derived load. Units and plausible ranges validate without deleting outliers silently. Recovery signals are contextual and non-diagnostic. Pain/illness/urgent indicators are not readiness scores. Plan versus actual remains distinct.

## Acceptance criteria

- Running, strength, calisthenics, explosive, mobility, stretching, and hand training fit without one universal metric.
- Load calculations preserve method/input versions.
- Deletion/permission changes invalidate derivatives and AI context safely.
