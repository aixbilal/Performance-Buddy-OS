# 32.14 — Development Schema

## Entities

`DevelopmentPath`, `DevelopmentModule`, `PracticeTask`, `Project`, `ProjectMilestone`, `SkillEvidence`, `DevelopmentNoteRef`, and dependency/link records. Fields include technology/skill scope, learn-practice-build stage, order, prerequisites, target evidence, status, effort, source, assistance mode, and revisions.

## Invariants

Module completion requires its declared evidence; session time alone does not prove skill. Project milestones and learning modules may link but retain identity. AI-assisted and AI-off work are distinguishable. Repository/file references obey permission boundaries and do not import credentials.

## Acceptance criteria

- Dependency/order cycles fail validation.
- Skills trace to concrete evidence and project revisions where applicable.
- Academic links use references without transferring ownership.
