# 32.10 — Curriculum Schema

## Entities

`CurriculumVersion`: program, source, effective/cohort scope, status, verification. `SemesterDefinition`: ordinal/label and curriculum link. `CourseDefinition`: official code/title, credits, theory/lab type, department. `CurriculumCourse`: semester placement, required/elective role, credit override/source. `PrerequisiteEdge`: prerequisite/co-requisite type, conditions, source/version.

## Invariants

Published versions are immutable; corrections create revisions/new versions with impact review. Similar course labels/codes do not imply identity. Credit and prerequisite rules require verified applicability. Graph cycles and missing course references are rejected or quarantined as unresolved imports.

## Acceptance criteria

- One program supports parallel cohort/effective curriculum versions.
- Prerequisite queries are reproducible from a frozen graph version.
- Imports preserve raw values and source locations for reconciliation.
