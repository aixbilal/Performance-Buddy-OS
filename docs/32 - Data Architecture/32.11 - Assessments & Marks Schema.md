# 32.11 — Assessments and Marks Schema

## Entities

`AssessmentPolicy`, `AssessmentCategory`, `CourseAssessmentScheme`, `AssessmentItem`, `MarkRecord`, `GradePolicy`, `RepeatPolicy`, `GradeResult`, and `CalculationRun`. Definitions store applicability, source, verification, version, weight/max, and override lineage.

## Invariants

Raw entered/imported marks remain separate from normalized values. Marks respect bounds and item identity; correction revisions preserve originals. Category weights and scheme rules validate before publication. Grade/GPA/CGPA results are derived snapshots with exact input/rule manifests and publication state (`PERSONAL`, `DERIVED`, `SCENARIO`, etc.).

## Acceptance criteria

- Identical inputs/rules reproduce identical results.
- Scenarios never overwrite actual marks or official results.
- Missing/conflicting policy blocks authoritative publication with diagnostics.
