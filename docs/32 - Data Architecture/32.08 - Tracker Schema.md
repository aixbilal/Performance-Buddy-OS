# 32.08 — Tracker Schema

## Entities

`TrackerDefinition`: type, owner, unit, target/rules, privacy, version, lifecycle. `ScheduleRule`: recurrence, timezone, effective interval, window, exceptions. `TrackerOccurrence`: deterministic expected instance and generation version. `TrackerRecord`: occurrence, observed value/state, partial/rest/excused reason, evidence, actor/time, revision. `MetricProjection`: disposable derived result.

## Invariants

Value shape matches boolean/count/duration/numeric/multi-check/milestone/reflection type. Units/ranges are validated. One effective record per occurrence unless the type permits samples; corrections supersede with history. Definition revision does not reinterpret history silently.

## Acceptance criteria

- Occurrence generation is reproducible across timezone/recurrence changes.
- Rest, excused, partial, skipped, missed, and unknown remain distinct.
- Streak/consistency projections rebuild without modifying records.
