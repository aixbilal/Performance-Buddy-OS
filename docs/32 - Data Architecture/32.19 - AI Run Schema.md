# 32.19 — AI Run Schema

## Entity

`AIRun`: application/prompt/schema/policy versions, capability, trigger, purpose, status/state transitions, user/permission/consent references, context manifest/hash, provider/model/runtime/adapter/settings, tool call refs, budgets/usage, outputs, validation refs, recommendation refs, checkpoint refs, errors, timestamps, latency/cost, cancellation, cleanup, and retention.

## Rules

Run status follows Phase 24/29 state machines. Raw prompts/context/output are stored only when policy permits; audit prefers hashes/references/redaction. Secrets and private chain-of-thought are never stored. Retries share a correlation chain but have distinct attempt IDs. A completed inference is not a completed write.

## Acceptance criteria

- State history is append-only and transition-valid.
- Run replay/debug data cannot leak never-AI or unauthorized content.
- Failure/cancellation records prove whether any owner commit occurred.
