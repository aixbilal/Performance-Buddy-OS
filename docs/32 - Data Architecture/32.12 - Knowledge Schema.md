# 32.12 — Knowledge Schema

## Entities

`KnowledgeEntity`: concept/skill/procedure/formula/question type, canonical label, aliases, description, owner context, verification/state. `TopicLink`: parent/related/prerequisite role and order. `KnowledgeSource`: source ref, coverage, authority, permissions. `NoteReference` and `AttachmentReference` point to external files without owning them.

## Invariants

Labels do not define identity. Aliases do not merge automatically. Merge/split history preserves redirect and evidence mapping. Topic graphs enforce allowed cycles/relations. Source deletion or permission change invalidates derived indexes, not unrelated knowledge identity.

## Acceptance criteria

- Renames, merges, splits, and external file moves are auditable/recoverable.
- Cross-domain consumers reference knowledge IDs without redefining meaning.
- AI-created knowledge entities remain drafts until confirmed.
