# 29.23 - Agent Council & Coach Room
## Concept

The Coach Room is an inspectable workspace for complex, user-initiated or policy-eligible multi-agent consultation. It is not an uncontrolled group chat or a background authority.

The view shows the Head Coach's question, participating agents, data scopes, findings, evidence, disagreements, time/cost budget, provider disclosure where relevant, and final synthesis. Users may expand specialist detail, exclude a participant, stop the run, or request revision.

Council runs use bounded rounds and typed messages. Only the Head Coach produces the final candidate; deterministic rules then validate and the user approves or rejects. Proactive council use respects Today/Focus scheduling and never interrupts active focus arbitrarily.

## Acceptance criteria

- Participation and data access are visible and revocable.
- Council loops terminate at configured limits.
- The final proposal retains dissent and provenance.
- Closing the room cannot leave an unreviewed write pending.
