# 31.11 — Manual Handoff Workflow

## Baseline workflow

1. Choose a bounded task and destination.
2. Select permitted sources/categories.
3. Verify current destination controls and account context.
4. Build the package locally.
5. Review manifest, redactions, exposure, retention assumptions, and requested output.
6. Explicitly approve and download/copy the package.
7. Manually transfer it; Performance Buddy OS does not claim upload success.
8. Perform external work.
9. Export/copy only the desired result and cited sources.
10. Re-import through quarantine, validation, and optional proposal approval.
11. Record completion/abandonment and clean up local packages.

## UX rules

Provide checklists, previews, editable scope, cancel, expiry, and destination-neutral instructions. Avoid dark patterns and repetitive consent. The user can choose a local/manual deep-work pack instead.

## Acceptance criteria

- Tests cover cancel at every step, changed package, wrong destination, expired consent, and partial result.
- No clipboard/download/upload event is inferred without evidence.
- Abandonment leaves trusted state unchanged and supports safe cleanup.
