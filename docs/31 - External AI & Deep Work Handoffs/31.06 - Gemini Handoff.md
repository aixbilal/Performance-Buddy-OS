# 31.06 — Gemini Handoff

## Intended use

Gemini may be evaluated for bounded deep work that benefits from its currently documented modalities, reasoning, or Google ecosystem context. No such capability is assumed by baseline.

## Workflow

Create the standard context export package; select only task-relevant files/fields; review provider disclosure; manually transfer through a user-controlled Gemini surface; request a structured artifact with source references and uncertainty; then import selected results through quarantine.

## Verification requirement

Current model/surface capabilities, file limits, integrations, data use, retention, workspace controls, region, price, and export/deletion behavior are `RESEARCH REQUIRED` from primary Google documentation. Consumer and organizational account policies must not be treated as identical.

## Boundaries

No implied permission from Google account linkage, Drive access, sync, or prior handoff. External connectors must not expand the package source set. Returned calculations, citations, and claims are independently checked.

## Acceptance criteria

- Destination/account policy is disclosed and recorded before transfer.
- Package scope cannot be expanded by connected external services without new consent.
- Failure or unavailable capability preserves the package for another/manual path.
