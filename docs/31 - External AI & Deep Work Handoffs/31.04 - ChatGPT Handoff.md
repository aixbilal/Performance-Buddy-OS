# 31.04 — ChatGPT Handoff

## Purpose

Define a manual, user-approved package transfer to ChatGPT for bounded analysis, study, drafting, or scenario work.

## Workflow

Choose task and permitted sources; generate a vendor-neutral package with task brief, evidence files, citation map, constraints, and requested output schema; review/redact; disclose remote processing; then manually upload/paste into the user's chosen ChatGPT workspace. Import only the selected final artifact through 31.13.

## Current-product caution

OpenAI documents ChatGPT workflows that operate on user-provided data and files in its [official use-case library](https://learn.chatgpt.com/use-cases?category=data). Exact file support, limits, projects, memory, retention, workspace controls, model availability, and data-use settings must be rechecked in current official OpenAI documentation before implementation or sensitive use.

## Boundaries

Never include credentials, never-AI/local-only fields, undisclosed private categories, or source text without rights/permission. ChatGPT memory and project context are external to Performance Buddy OS. Returned citations and calculations are reverified locally.

## Acceptance criteria

- Package preview names every included category/file and destination.
- Current OpenAI control/retention assumptions are documented at handoff time.
- ChatGPT output re-enters only as an untrusted, source-linked draft.
