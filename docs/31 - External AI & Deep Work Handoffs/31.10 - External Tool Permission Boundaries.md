# 31.10 — External Tool Permission Boundaries

## Permission intersection

Export authority is the intersection of user, source/domain, data-zone, task/purpose, destination/provider, account/workspace, operation, retention, and time permissions. The strictest condition wins.

## Prohibitions

Never export never-AI or local-only data; credentials; hidden system prompts; unrestricted databases, vaults, drives, repositories, or device paths; third-party/private material without rights; or categories not listed in the preview. Sync, cloud backup, sign-in, a prior handoff, or provider connector access grants no handoff permission.

## Sensitive data

Ask-every-time categories require fresh category-, task-, and destination-specific consent. Aggregates, filenames, embeddings, summaries, and metadata inherit source restrictions. External sharing/collaboration is a separate disclosure and permission.

Revocation stops future exports and invalidates local derivatives; deletion from an external provider follows that provider's verified controls and cannot be falsely claimed by Performance Buddy OS.

## Acceptance criteria

- Exfiltration, metadata, aggregation, connector, archive, and destination-switch tests fail closed.
- Users can inspect/revoke permissions without affecting owner records.
- Unknown provider controls block sensitive export or require resolution.
