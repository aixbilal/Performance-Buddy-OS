# 31.03 — External Tool Selection

## Decision inputs

Select a destination for one declared task using source-grounding needs, supported file/modalities, context size, citation behavior, output format, privacy/data controls, retention/training policy, account/workspace controls, region, accessibility, cost, availability, and user preference.

## Rules

Hard privacy and permission constraints filter before quality or convenience. Current product capabilities and limits are `RESEARCH REQUIRED` from primary vendor documentation because they change. Performance Buddy OS does not claim one tool is universally best. A user may choose no external tool or export a vendor-neutral package for manual work.

Selection records evaluated date, evidence links, assumptions, destination/account context, package compatibility, and reason. Changing destination triggers a new disclosure and package review.

## Acceptance criteria

- A versioned decision matrix separates verified facts from observations and preferences.
- Unknown retention, training, region, or security behavior blocks sensitive exports or is resolved first.
- Tool outage/plan limits do not weaken package privacy or remove manual alternatives.
