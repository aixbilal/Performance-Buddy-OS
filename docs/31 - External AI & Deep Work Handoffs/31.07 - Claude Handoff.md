# 31.07 — Claude Handoff

## Intended use

Claude may be evaluated for bounded long-document analysis, drafting, critique, or code/design reasoning where current verified capabilities match the task. Baseline does not assume model, plan, project, connector, or context features.

## Workflow

Generate the same vendor-neutral brief, source inventory, evidence excerpts/files, constraints, output schema, and citation requirements; preview and disclose; manually transfer; then re-import only a selected artifact.

## Verification requirement

Supported content, limits, model availability, account/workspace controls, retention, data use/training, sharing, region, cost, and deletion are `RESEARCH REQUIRED` from current primary Anthropic documentation before implementation or sensitive use.

## Boundaries

Do not provide credentials, never-AI/local-only data, unrestricted repositories/vaults, or hidden system context. An external project/memory is not Performance Buddy OS memory. Code or recommendations return as untrusted drafts requiring tests and owned validation.

## Acceptance criteria

- The handoff remains useful without vendor-specific package structure.
- Imported claims/citations resolve to permitted original sources.
- Destination changes require a new preview, disclosure, and approval.
