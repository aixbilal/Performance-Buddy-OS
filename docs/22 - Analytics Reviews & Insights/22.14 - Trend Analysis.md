# Trend Analysis

## Purpose

Describe sustained directional change while distinguishing signal from noise, seasonality, mode changes, and incomplete data.

## Methods

Rolling windows, period-over-period change, moving summaries, distribution shifts, and simple deterministic slope/change-point indicators may be used with declared parameters. Exact statistical techniques and thresholds are versioned and evaluated before promotion.

## Rules

Show raw observations alongside summaries. Minimum sample and coverage requirements apply. Missing is not imputed without a visible rule. Definition changes split or remap a series explicitly. Outliers are retained and annotated, not deleted automatically. A trend does not prove cause or predict continuation.

## Output

Direction, magnitude/unit, window, coverage, uncertainty, change context, and alternative view. Avoid false precision and alarming language.

## Acceptance criteria

Fixtures reproduce results, parameter changes create versions, sparse data yields `INSUFFICIENT EVIDENCE`, and user corrections propagate without rewriting source history.
